- **补充**：
  - 新增“安全暂停”态（GPT-F09）；
  - 新增工具状态四元组文案契约（T01–T03）；
  - 产物三分类徽标（W01）；
  - 执行位置标签（book1）；
  - S01–S05 四档授权（全部允许仅限个人账号）。

## 4. 优先级建议
- **P0**：
  1. Rust core 落地本地幂等/回执账本（**硬性要求**）。
  2. “结果未知”独立状态，并禁止盲目重试。
  3. 生成式 UI 只允许白名单宿主动作，禁止直接副作用。
  4. 撤权后立即生效。
- **P1**：
  5. 工具状态四元组文案契约。
  6. 确认卡绑定对象和版本，旧卡片失效。
  7. S06（不含临时会话/容量上限）与 S07 定稿。
  8. 分享/导出按用途裁剪。
- **P2**：
  9. 产物三分类徽标、压缩回执、消息树多版本。
  10. 字体/排版常量。
  11. 安全暂停后的复核流程。

## 5. 已决定（用户，2026-10-13 18:18）
1. **本地防重复 + 回执账本：Rust core 执行/回执模块强制项。**action_id 唯一约束 + INSERT OR IGNORE；验收：重复点击返回原回执、恢复时先查账本、结果未知先核对（CL-F02，GPT-F13）。
2. **生成式卡片禁止直接触发副作用动作**；必须走“新一轮请求 → 授权 → 确认”（GPT-F03）。
3. **不做安卓屏幕上下文读取。**
4. **授权四档确认**：每次询问 / 允许读 / 允许低风险 / 全部允许；“全部允许”仅限个人账号。
5. **S06 不加临时会话，也不设记忆容量上限。**
