# 平台层测试覆盖率（2026-10-05）

范围：`apps/muyon` 的 `lib/platform/**`、`lib/workspace/**`、`lib/services/models/**` 行覆盖率。
方法：`flutter test --coverage` 生成 `apps/muyon/coverage/lcov.info`，按 lcov `LF`/`LH` 统计行覆盖。

## 可重复运行的命令

```sh
cd apps/muyon
# 本机代理会破坏 flutter 的 localhost 测试 websocket，先清掉（scripts/verify.sh 同样处理）
unset HTTP_PROXY HTTPS_PROXY ALL_PROXY http_proxy https_proxy all_proxy
export NO_PROXY=localhost,127.0.0.1,::1
flutter test --coverage
python3 - <<'EOF'
from pathlib import Path
PREFIXES = ("lib/platform/", "lib/workspace/", "lib/services/models/")
files, current = {}, None
for line in Path("coverage/lcov.info").read_text().splitlines():
    if line.startswith("SF:"):
        current = line[3:]
        files[current] = [0, 0]
    elif line.startswith("LF:") and current:
        files[current][0] = int(line[3:])
    elif line.startswith("LH:") and current:
        files[current][1] = int(line[3:])
rows = [(n, *v) for n, v in sorted(files.items())
        if any(p in n for p in PREFIXES)]
lf = sum(r[1] for r in rows); lh = sum(r[2] for r in rows)
print(f"TOTAL {lh}/{lf} {100.0*lh/lf:.1f}%")
for n, f, h in rows:
    print(f"{n} {h}/{f} {100.0*h/f:.1f}%")
EOF
```
