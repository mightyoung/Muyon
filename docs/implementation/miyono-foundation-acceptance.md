# Miyono 个人助手与共享平台建设记录

日期：2026-10-04。依据用户最新提供的初始需求，优先建设个人 AI 助手、统一基础平台与公共能力。MuSpace 保留为仓库、包名及数据库标识，界面显示 Miyono。Folio 与科研模块继续保留完整业务页面，作为共享平台的实际调用场景。

这是本地实现与验证记录。不是完整总体产品、三端实机或发布验收声明。

## 初始需求对照

| 职责 | 本轮实现 | 边界 |
|---|---|---|
| 主对话与专题对话 | 持久主会话、工作区/业务对象专题会话、桌面并排助手、手机独立页面 | 业务对象以真实 module/type/project/id/version/digest 定位，不伪造全局项目 |
| Agent 业务调用 | 实际工具发现、参数校验、范围解析、权限、持久调用记录；原 Folio 查询、比价、规格匹配与预算规则；科研对象与共享资料工具 | Folio 原只读工具与完整页面复用。通用文件导入不是自动导入供应商或科研业务；业务写入仍走已有页面确认，后续逐项注册 |
| 个人助手任务 | 多轮真实模型请求与工具循环、结果引用、执行设备/等待原因/产物、取消/暂停/新尝试恢复 | 写入与外传逐次确认；恢复重新确认，不自动重放不可逆操作；页面关闭不取消宿主任务 |
| 记忆与经验 | 来源、作用范围、确认状态、版本、过期、查看/编辑/删除；后台生成只读重复候选、显式属性变化候选及来源摘要 | 不把属性变化说成已证实矛盾；不自动删除来源或生成新经验。Dream、语义矛盾识别与自动经验提炼后置 |
| 工具选择 | 可注入 ToolSelectionStrategy，默认离线规则与模型候选；任务保存策略及冻结候选 ID，拒绝模型越界提案 | Jev/Laya 未选为生产模型，尚无决策方法效果比较 |
| 工作台 | 项目/工作区、近期会话、任务/消息/个人/设备/设置入口及完整 Folio/科研入口 | 以四个主导航组织职责，不把各中心扩成独立应用 |
| 消息中心 | 助手/设备操作完成通知、通信收件提示、已读管理、回到任务或待核验收件 | 在线收件不自动接纳到业务库 |
| 任务中心 | 汇总个人任务、原科研执行记录、原 Folio AI jobs、工具回执 | Folio jobs 保留原任务库及恢复规则，不复制第二个权威；传输不提供虚假的逐项暂停/恢复按钮 |
| 个人与系统设置 | 姓名/设备 ID、记忆、统一主模型/嵌入模型、系统凭据、主题、减少动态效果、私有存储和能力权限状态 | 模型位置/端点显式选择，无隐式云回退；chat/embedding 配置隔离 |
| 数据与知识中心 | 私有文件复制、文件预览、全文检索、来源对象目录与跳转；原研究关系与业务图继续保留 | 检索源摘要变化拒绝继续；对象目录以查找和跳转为主，没有新建全域自动知识图谱 |
| 接口与工具中心 | 真实 provider 注册、可用性、参数、权限、目的地、调用记录与结果引用 | 静态业务模块，尚不支持下载并执行任意第三方插件代码 |
| 文件公共能力 | PDF/文本等导入解析、PDF/文本/图片预览、私有副本、OCR 索引、包导出 | 既有业务包、XLSX/PDF 等专业导入导出继续留在完整模块中，不删减原流程 |
| PaddleOCR | 固定官方 PP-OCRv5 mobile det/rec、模型文件大小与 SHA-256、BGR/DB/旋转裁剪/CTC、图片与扫描 PDF、坐标/置信度/来源元数据 | 用户确认后下载安装模型；识别在本机，不上传图像。真实 ONNX 参考推理通过，Flutter 原生插件实机尚待验证 |
| 全文/RAG/向量 | 单一共享 KnowledgeService；科研界面用 ResearchSearchAdapter 实际复用；FTS5/BM25；真实 embedding 请求、来源/模型/维度绑定与已建向量离线检索；限定论文 QA 保留冻结证据/可信引用 | 未宣称已有混合检索、reranker、真实科研语料质量评测或生产语义 RAG 评测 |
| 模型公共能力 | 个人助手、科研与 Folio 实际共用宿主网关/配置/凭据；保留原 Folio LlmClient 的业务工具、检查点与规则 | 本机、本人设备、自选远程端点均显式配置。模型缺失/拒绝/取消不自动改端点 |
| 设备与交换 | 私有校验包、跨网络自选渠道、在线 LAN 一对一文字/链接/附件、可达设备、字节进度、接收回执、待核验收件与重启恢复 | LAN 明文且无强身份认证，仅明确启用的本人可信网络；内容摘要证明完整性，不证明发送者身份。公网/离线 IM、群聊、全库自动同步后置 |

## 实际验证

- 完整宿主回归：**73 通过，1 条件跳过**。跳过项为依赖显式真实模型/Python 环境的 OCR 数值参考测试；该项另有真实执行证据。
- 公共模块接口：**10 通过**；完整宿主静态分析：**No issues found**；`git diff --check` 通过。
- 助手与执行恢复：**12 通过**，含实际 HTTP→工具→再次请求→来源答案，以及注入策略/冻结候选越界拒绝。
- Folio 统一模型适配：**7 通过**；共享配置/取消模块回归 **2 通过**；完整 Folio 页面入口 **2 通过**。
- 工作区/过期文件/软删除对象范围：**3 通过**。修复空绑定 null 相等造成的范围扩张、原 get 返回软删除内容和其他定点参数越界。
- 设备协议与关闭安全：**12 通过**。真实 HTTP 验证发送进度单调、发完仍等待回执，以及关闭时强制终止并排空原先可能等待 15 分钟的连接。
- 公共服务：**8 通过**，包括真实 HTTP embedding 后离线检索、文件/索引失效、包篡改/路径/重复接纳/取消、伪造成员摘要、实际字节冻结发送、启停竞态、未核验收件重启恢复。
- 真实 OCR 另行执行：官方固定 ONNX + Python ORT 1.23 CPU 推理，复用实际 Dart 前后处理；中英文金额、12 度倾斜图像、真实 PDFium 渲染的扫描 PDF 断言通过。直立样本输出 `Miyono invoice 123.45`（0.9768）、`材料采购金额 678.90`（0.9632）。详见 `apps/muspace/test/public_services_validation.md`。
- UI/升级/生命周期：**7 通过**；覆盖 320/390/430/1280 宽度、200% 字号、桌面助手并排、v1→v2 保留旧工作区/设置/原任务字节、同一 execution_records 权威，以及关闭宿主等待平台任务并拒绝新工作。

上述定向测试与完整宿主测试有重叠，不应相加成独立总数。此前供应商 465 核心/309 UI 与科研 95 项是迁入阶段历史证据，本轮未重新声称这些整套回归已再次执行。

## 交付与平台验收

Android 最终构建正在验证，结果将追加在下方。构建开始前已结束全部 Flutter 测试，避免测试与发布构建改写同一生成插件注册文件。

当前 `adb devices` 未发现连接设备。macOS 仅有 CommandLineTools，`xcodebuild` 明确要求完整 Xcode；Windows 无本机工具链。三端原生 OCR、最低系统、真实双设备通信、系统凭据、文件保存/重开与设备性能不能在本环境中声明通过。

本次 ONNX Flutter 依赖要求 **macOS 14+**，宿主工程已同步配置；这改变了旧 Folio 的 macOS 12 兼容范围。Windows 首轮配置固定 ORT 1.23 x64 下载路线，尚待原生包哈希/分发及实际构建验收，不能宣称 Windows ARM64 支持。

Android 当前构建链保留已验证的 AGP 8.11.1/Kotlin 2.2.20/Gradle 9.3.1；Flutter 已提示未来版本支持将变化。安装包为开发签名，不等同正式发布。

## 主要代码位置

- `apps/muspace/lib/screens/`：平台工作台、助手、设备与资料预览。
- `apps/muspace/lib/assistant/`：宿主个人任务与可替换工具选择。
- `apps/muspace/lib/platform/`：主库、范围/工具/审批回执及只读记忆整理。
- `apps/muspace/lib/services/`：共享知识、向量、OCR、模型与交换。
- `apps/muspace/lib/app/inquiry_plugin.dart`、`packages/inquiry_module/lib/src/app/shared_models.dart`：成熟 Folio 实际共享模型适配。
- `packages/supplier_core/lib/lan.dart`：轻量 LAN 出口；原 LAN 协议的关闭排空/可见字节进度扩展。

原需求、修订 4 共识、源基线与历史迁入验收文件均保留。没有提交、推送、CI、合并或正式发布声明。
