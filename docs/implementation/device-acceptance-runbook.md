## 二、科研完整链（两台设备：A 执行整理，B 执行任务）

前置：B/C/D 第 1 阶段合入 `develop`（引用定位 C3、研究包 C4、加密配对 D1/D2）。

1. A：新建工作区"实际项目"，在科研模块导入 research-workflow 产出 → 研究卡、关系图、提纲可见。
2. A：导入论文（文字层 + 扫描件）→ 扫描页经 OCR 可检索；阅读、批注、摘录、保存研究卡。
3. A：中文短词与中英混合检索命中预期论文；限定所选论文问答，答案带引用，点击回到原页；无充分证据时明确说明。
4. A：断开网络重复第 3 步的阅读与检索 → 仍可用；问答明确提示模型不可用，不改用其他端点。
5. A：创建实验任务并导出任务包。
6. A↔B：首次配对（双方比对指纹）→ 通过加密通道发送任务包；B 显示接收、校验通过，但未导入、未执行。
7. B：人工接纳导入 → 本机授权后执行 → 导出结果包 → 发回 A。
8. A：接纳结果，进行人工评估与比较，否定或接纳结论并写明理由；关联提纲，导出报告。
9. A：退出应用并重开 → 资料、批注、研究卡、决定与关联仍在；"数据去向"记录与 A↔B 传输状态可查。
10. A→B：导出完整研究包（不是任务包），B 导入 → 原文件、卡、引用、关系和版本完整；B 修改后回传 A → 分叉保留、不覆盖。
11. 失败分支：传输中断网、重复发送同一包、原文换版后打开旧引用、取消一次进行中的问答。
