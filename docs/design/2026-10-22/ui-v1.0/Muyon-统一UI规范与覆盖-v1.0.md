## 不可混淆的状态与操作
- 保存附件≠读完全文；已提取页、失败页、索引范围分别呈现。未知总量不造百分比。
- 来源可定位≠主张被证实；被引用来源≠全部检索结果；同源不算独立证据。
- 普通选择/编辑仅改本地草稿，不发送、不授权。保存草稿和提交记录有独立动作及回执；无回执不显示已保存。
- unknown不是failed；写入结果未知查询原intent回执，不盲重发。停止/取消请求不等于取消成功，不意味着回滚外部动作。
- 修改批准和结果披露批准分开；目标、参数、scope、digest、expected_revision变化使旧批准失效。按钮必须来自宿主可信对象，不从Markdown执行。
- 预占与实际费用分字段，未知不写0；示例金额不是本次新增账单。普通点击不绕过费用、网络或写权限门控。
- 报告新版本追加，冲突先比较；预览不是保存。历史回执不是当前记录状态。

## 组件与交互契约
组件以稳定component_id/message_id/conversation_id/project_id/revision身份绑定；有限原生kind及白名单action，未知类型安全降级。动作区分本地编辑、打开来源、填入草稿、提交本地记录、请求宿主动作。幂等intent、版本校验和宿主回执是事实来源。
菜单点遮罩/关闭按钮收起，背景不得点击穿透；保存草稿和滚动锚点。返回先处理键盘/最上层弹层/菜单，再离开页面；不得一次返回丢草稿。选中项同时有语义selected、非颜色标记和读屏描述。正文来源返回原锚点。
加载/失败不能清空已有内容；持久错误和需决定信息不只toast。减少动效/可隐藏吉祥物装饰，所有功能不依赖角色动画。深浅色、焦点、禁用、按下、长文本、小屏和字体放大需代码层独立验收。
