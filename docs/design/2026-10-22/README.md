## 已定与建议

用户已定：柔黑柔白，避免纯黑白与大面积米棕；菜单上方为主 Agent 及置顶单聊/群组，普通会话在下；菜单展开和对话按用户参考图布局；人类群主权限与任务协调 leader 分离。原 m 图标必须使用原资产，生成图中的变体不得替换品牌资产。

仍为建议或待验：具体 token、尺寸、动画、底部导航、置顶重排、Bot 推荐机制、群组默认模式、HTML/地图/连接器及外发能力。图 06 是用途步骤，图 09 三选项未预选；九图均是设计示例，不能切图当生产控件。深色逐屏、200% 字号、48dp、读屏、返回栈和真实状态须另行验收。不得由视觉批准推定外部请求、账户权限或付费授权。
