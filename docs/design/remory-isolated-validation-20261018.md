## 0. 结论与当前边界

三项候选分别验证、分别决策：

1. **结构化补充信息**：FailureObservation、DecisionSupersession、EvidenceLink 是否在公平预算下，比更长摘要和摘要＋检索带来真实任务收益。
2. **事务式压缩协议**：CAS 发布、崩溃恢复、删除/撤权派生失效及 unknown 回执保留，是否在故障环境中提高真实模型任务的正确恢复能力，并且没有不可接受的正常任务退化。
3. **神经软 token 后端**：公开实现是否可复现、安全且比最佳非神经方案有额外收益，总成本和资源是否值得。

**软件合同验证通过 ≠ 模型任务有效 ≠ 允许生产实施。** 任何一层失败或证据不足，都不得用另一层的成功抵消。三项不打包批准：文本对象有效不代表 CAS 新方案已有效，前两项有效不代表神经后端获准。

本轮只读取公开资料与候选文档、编写此方案；未运行产品代码、模型、训练、测试、GPU 或付费任务，未修改 Muyon 仓库。下文所有样本数、统计阈值、预算与技术选项均为**待用户/项目负责人冻结的建议**，不是已经批准的参数。

“隔离实验原型”专指在已有实验授权及环境权限范围内、与生产分离的模拟器/评测适配器。按用户当前“继续并先实验”的要求，已有授权环境内低成本、本机、合成数据的软件验证及必要测量原型可继续，**不逐个 fixture 重复请求批准**。本方案作者的当前分工仅为编写协议；不表示整个项目需要等待新的软件验证授权。

原型不能进入生产构建、真实账户、生产数据库或默认功能，也不能把它视为生产实施的第一片。真实模型费用、GPU、额外下载/付费、新增敏感数据或传输目的地、持久访问或环境权限扩张若不在现有授权内，先补齐相应范围与预算；只暂停依赖缺失授权的部分，继续其他已授权验证。已获明确批准的执行参数和重试不重复确认。

## 4. 数据构建：覆盖真实弱点，也保留负对照

### 4.1 单个样本结构

每个任务包至少包含：`task_id`、`family_id`、业务域、难度/长度层、已获授权的初始快照、因果事件流、合法工具/状态机、独立金标准、故障计划、可评分产物、结束条件、来源与许可。

模型与记忆构建器只能看到当前时点之前的可见历史。金标准、未来回执、未来用户修改、目标答案及评估者解释只交给评分端，不能挂载或检索到生成端。

### 4.2 三域与拆分

- 科研/资料证据域：多来源同名结论、版本更新、错误或不可读链接、证据与主张错配、检索失败后恢复。
- 询价/工作流域：参数或价格版本变化、局部需求替代、过期报价、取消后迟到回执；全部交易和发送动作只在模拟器中发生。
- 独立第三域：使用不同字段与工具的合成维修/资产记录等工作流，由另一出题者构建，检验公共内核是否仅针对前两域写死。

优先使用合成或明确许可的公开数据；拟用真实用户/项目轨迹时，另列具体数据、去标识方案、模型服务接收方及授权。脱敏并不自动等于获准外传。首轮不把私有轨迹交给公共在线模型。

拆分单位是**来源家族/任务模板/项目/会话**，不是单条消息。原任务、改名版、数字替换版、同一文档的不同切片、同一用户轨迹的不同压缩点必须在同一分区。预设时间外推子集与此前未见工具 schema 子集。

### 4.3 必须纳入的分层

1. 没有压缩、一次压缩、多次压缩；多次层建议覆盖 3 次和 5 次以上压缩。
2. 同条件重复失败与条件确实改变后的合理重试，两者必须都有。
3. 全量/局部决定替代、相互冲突、来源不充分、模型伪造用户决定。
4. 工具 timeout/断连后 `outcome_unknown`，以及随后出现成功、失败、仍未知三种回执路径。
5. CAS 竞争、新消息/取消/撤权/删除穿插、崩溃恢复、迟到回执、备份恢复。
6. 可容纳预算、临界预算、必须暂停的不足预算；合法信息无法装入时的正确暂停。
7. 来源改写/缺失、跨用户/项目/分支的近似记录、检索中提示注入、插件伪造可信声明。
8. 不需要三对象的普通任务、已在近期上下文中的信息、完全没有有用补充信息的负对照。

每个任务先定义可观测正确结果。对本来无法完成、无授权或无可知结果的任务，正确暂停/保留 unknown 可以算成功；对本来可完成的任务，单纯拒绝/停止算失败。禁止靠“所有任务都暂停”提升安全或正确率。

### 4.4 建议样本规模及其限制

- V1：CTX-T01–T14 各有正例、反例与竞争变体；再加有界状态空间枚举和预注册随机故障序列。覆盖规模以实际状态组合为依据，不能仅以“14/14”代表充分覆盖。
- V2：建议 90 个家族独立任务，三域各 30；每任务固定至少 3 个运行 seed。只作调试与功效/成本估计。
- V3：可先以 600–1,200 个独立任务作为资源估算区间，正常与故障条件分层、三域平衡；**这不是已证明足够的样本量**。实际 N 由 V2 的成对差异/家族聚类方差、主要对比数、拟检出的效应和功效目标确定。
- V4：从新来源/新家族建立新的复核集，建议规模为 V3 的 25%–50%，仍需能回答预注册复核问题；不能以极小复核集宣称普适稳定。

若授权预算只能支持不足功效的小样本，诚实输出“可行性/探索性证据”或“不确定”，不降低标准以获得准入。重复 seed 不能当作更多独立任务，多个压缩点也不能当作独立人群样本。

## 5. 公平基线与因果隔离

### 5.1 必须保留的非神经实验臂

| 代号 | 内容 | 作用 |
|---|---|---|
| B0 | 冻结的现有四字段摘要行为参照＋共同保留的近期历史/安全状态 | 说明相对现有方案变化；历史 Dart 参照不等于 Rust 已实现 |
| B1 | 同预算优化的更长摘要/文本补充＋相同档案查询能力 | 排除只是给候选更多上下文或更好提示词 |
| B2 | 优化摘要＋明确可用的来源/事件检索，召回与重排策略冻结 | 最重要的简单强基线 |
| T | 摘要＋三类结构化对象＋与 B2 相同的原文检索 | 候选 1；不额外开放来源或工具 |
| FULL | 在上下文确实容纳时使用全部合法历史 | 信息上限诊断，不当作等成本主要对手 |

共同安全状态包括当前授权、未决调用/unknown 的权威指针和不可丢失的用户输入；不得为了抬高候选收益，故意删除基线已有的这些保护。B1 允许在普通文字中自然保留失败、决定和证据内容，不能刻意禁止其记住候选所需信息。

### 5.2 两种预算视角同时报告

**固定资源主分析**：相同 actor、总上下文位置上限、输出 token、工具次数、截止时间和任务总费用上限；记忆对象、字段名、检索结果、检索参数/回执、摘要与近期原文都计入。摘要/提取调用次数和成本必须受同样总上限约束。

**质量—成本曲线辅助分析**：在开发集预先选择几个预算点，报告完整收益/成本/延迟曲线。相同 token 数不等于相同美元或延迟，尤其神经编码/缓存/工具成本不同。不能只挑候选最有利的预算点。

可在 V2 比较额外 512/1,024/2,048 个文本 token 等预算点，但最终位置数必须结合 actor 窗口冻结；不机械沿用论文 4,096 软槽作为文本对象上限。

### 5.3 把“表示”“事务协议”“模型能力”拆开

表示 T 与事务协议 P 建议做 `B2/T × P0/P1` 的 2×2 因子实验，并为 B1 配同样的 P 条件：

- P0：冻结的既有安全策略/参考实现；不能故意关闭现有权限与账本保护。遇到无法安全恢复时允许安全暂停。
- P1：候选 CAS 发布、失效与恢复协议；与 P0 使用同样的 actor、文本表示、事件和权限边界。
- T 的主要对比在同一 P 条件下进行；P 的主要对比在同一表示条件下进行。必须报告交互效应，不能把组合增益全部归给某一个组件。
- 如果仅组合有效，可把结论限定为组合候选；不得声称每个组件独立有效或据此放行单项。

V2 可用消融诊断 FailureObservation/DecisionSupersession/EvidenceLink 各自贡献，确定最小方案；移除无收益组件是允许的。消融不能在看到 V3 结果后挑选有利子群替代主分析。

### 5.4 两层模型任务测试

1. **共同检查点续跑**：相同因果历史、基础摘要、近期上下文和压缩边界，对各表示生成下一动作，再在同一个可复位模拟环境里执行到预设终点。动作偏好可作诊断，但主要分数来自执行结果。
2. **端到端多次压缩**：从同一初态与外生事件计划开始，自主运行到成功/明确失败/预算耗尽。压缩触发规则一致，所有记忆位置计入窗口。轨迹自然分叉；不能事后强行只保留共同成功片段。

第一层回答“记忆表示是否改变正确决策”，第二层回答“整个系统是否值得”。第一层单独通过不能允许生产实施。

## 6. V1：可执行的离线合同验证规格

运行载体为隔离事件模拟器与真实存储接口的测试替身。仅生成合成事件，网络外发关闭，工具副作用记录到内存/临时沙盒账本。使用参考状态机作为 oracle，候选状态与 oracle 每步比较。

| 合同 | 输入/故障注入 | 必须观察到的结果 | 留证 |
|---|---|---|---|
| 来源与对象 | 缺引用、错 revision、跨 scope、伪造 verified、恶意降敏 | 拒绝或明确 unknown/conflict，不洗白来源 | 原事件、拒绝原因、投影差分 |
| 失败条件 | 同参数不同 intent；版本/环境变更 | 不以参数 hash 代替幂等；允许合法重评估 | intent/action/回执关联图 |
| 决定替代 | 局部替代、交叉范围、模型伪造、新旧冲突 | 仅有效用户来源改变对应范围，无授权扩张 | 有效决定投影与原始引用 |
| unknown | timeout、取消、无回执、迟到成功/失败 | unknown 不凭摘要改写；后续事实归原 invocation | 每步账本与模型可见状态 |
| CAS 竞争 | 生成中加入 turn、策略更新、删除、撤权 | 陈旧候选不可发布，重建有界 | 读集/版本/CAS 结果 |
| 原子提交 | 在写摘要、对象、覆盖清单、回执、指针各阶段前后崩溃 | 仅完整旧版或完整新版可见，无半提交 | 故障点、恢复快照、事务轨迹 |
| 迟到证据 | 旧 generation 收到真实结果 | 证据可归档，陈旧投影不得覆盖当前上下文 | 两条独立状态流 |
| 遗忘与恢复 | 删除/撤权后访问旧缓存、检索、导出、日志、备份 | 有效输出不出现失效内容，墓碑优先 | 派生图、访问记录、恢复检验 |
| 预算/失败降级 | 摘要失败、预算不足、旧上下文已失效 | 只回退仍合法状态；否则暂停，无静默丢失 | 预算与停止原因 |
| 插件缺省 | 无扩展声明；声明只读却试图写；不同第三域 | 通用引用回退；宿主拒越权，不因兼容放行 | 注册和调用审计 |
| 标识与边界 | call/result 跨压缩，未发送输入，多 store/stream | 不丢/不重发，不跨域比较无关序号 | ID 集合差分 |
| 模型/会话隔离 | 模型、prefix、scope、分支改变 | 拒绝不兼容派生对象/handle，合法文本降级 | 绑定校验结果 |

既有 CTX-T01–T14 全部保留对应关系。T14 的实际 Android/Electron UI 行为仍属后续工程验证，本轮模拟投影不能把真机项标通过。

V1 的建议通过条件：预注册强制合同断言全部通过，受检故障序列中零越权/零重复副作用/零被删内容复活/零 unknown 伪成功；覆盖与未覆盖状态明确列出。任何关键失败立即阻断后续模型实验。**即使全部通过，效益栏仍写“未测/未证明”。**

## 7. V3：指标、盲评和统计判定

### 7.1 主要效益指标

- 候选 T：在正常与多次压缩任务上的**任务正确完成率**，对 B1、B2 分别作成对比较；客观产物/状态验证优先。主任务成功必须满足预先定义的需求、证据和关键限制。
- 候选 P：固定故障压力下的**正确恢复并完成率**，对同表示 P0 成对比较；同时要求正常无故障任务的完成率非劣。自动暂停而未完成不能算恢复成功，除非任务金标准本来要求暂停。
- 候选 N：在相同 actor/运行时下，对最佳已验证非神经方案的额外任务收益；并通过所有安全、失效和成本门禁。

各主要对比均使用相同任务、初始状态与预设 seed；因环境允许行动而产生的分叉不得被人为修平。

### 7.2 错误与次要指标

1. 真正无效重复调用：状态、版本、权限、参数语义未变化，且无合法轮询/重试原因的重复；同时报告每任务绝对次数和每百个可行动机会次数。重复输出字节本身不是错误定义。
2. 过时决定复用率、局部范围错误率、新决定遗漏率；分母为存在相关决定的任务/机会。
3. unknown 误报成功、误报确定失败、错误解除阻塞；按有 unknown 的机会计数，任一真实副作用风险单独列严重事件。
4. 证据正确性与可核验率：主张是否被相应来源支持、revision 是否正确、可读权限是否有效；“带链接”不能等于正确引用。
5. 信息保留和恢复：关键约束/调用配对/来源 lineage 完整率，合法迟到回执归属，正确拒绝无授权访问。
6. 可用性：正常任务错误拒绝率、安全暂停率、恢复时间、争用下重建次数与饥饿情况。
7. 成本/性能：actor、摘要、提取、检索、重排、评分成本分列；总输入/输出/缓存 token，压缩与恢复延迟，端到端 p50/p95、总运行时、内存/存储。评分成本属于实验费用，产品成本比较应单独列示，不混入产品单任务费用。

神经臂额外报告特征编码与记忆网络时间、GPU 秒/时、峰值显存、模型加载/冷启动、KV/前缀缓存约束、并发/吞吐、存储及网络成本；训练成本若后来获准，则报告摊销假设与不摊销总额。

### 7.3 评分隔离与盲评

- 优先可复位环境的确定性 verifier。无法客观判断的文本产物由两名独立评估者按冻结 rubric 评分，第三人仲裁。
- 隐去实验臂、模型路径、成本、候选标签；随机 A/B 顺序。若格式泄露结构化方案身份，标为部分盲法；优先只比较最终产物，格式统一只能移除标签，不能改写语义。
- 不把候选隐藏推理当评分依据；只使用用户可见动作、结果、来源和合法环境状态。
- 报告评估者一致性、争议率与仲裁比例。若使用模型评委，冻结评委与提示，在人工标注集上校准；对所有关键错误、全部争议及随机抽样做人工复核，不由同一生成模型自评决定准入。
- 评委只在产物提交后访问金标准；其评分不能反馈给生成端或提取器进行锁定集调优。

### 7.4 统计单位与方法

- 主要估计量为任务级成对成功率差。每任务先汇总重复 seed；对任务族/来源家族做分层聚类 bootstrap 或预注册成对置换/模型方法，不能把一个任务的 5 次运行当成 5 个独立任务。
- 使用预注册多重比较校正。T 对 B1、B2 的比较与 P 的主要效益/非劣比较应列明同一检验族或清楚分开的决策族，控制各自家族错误率；建议采用 Holm 校正，并报告与决策一致的调整置信界限。
- 报告效应点估计、置信区间、样本量、缺失量与各层结果；不以 p 值或平均分单独作结论。分层结论仅限预注册且具足够精度的层。
- 建议最终锁定后只做一次效益判定，避免反复窥视后提前报喜。若确需序贯设计，必须在开始前冻结分析时点和 alpha spending；不能临时添加“再跑一点直到显著”。
- V2 使用估得的成对不一致率/聚类方差来规划样本量，建议目标功效至少 80%，高风险决策可设 90%；这些同样需冻结。成本上限不能反向证明功效足够。

### 7.5 待冻结的数值门槛建议

以下用于讨论，不是已获批准的验收线；正式执行前应结合可接受风险与基线水平冻结。

| 候选 | 建议效益门槛 | 额外约束 |
|---|---|---|
| T | 对 B1、B2 的任务完成率点估计均至少 +5 个百分点，调整后置信下界均 >0 | 正常负对照非劣界限建议 -2 个百分点；关键域逐域列效应与区间，是否要求逐域非劣及其界限须事前冻结 |
| P | 故障层正确恢复完成率相对 P0 至少 +10 个百分点，调整后置信下界 >0 | 无故障完成率的调整后置信下界 >-2 个百分点；关键安全事件为零观测 |
| N | 对最佳非神经基线至少 +5 个百分点，调整后置信下界 >0，独立批次方向一致 | 同 actor；P/T 的软件与泄漏门禁仍过；不能仅凭 token 下降 |

建议产品全成本比及端到端 p95 延迟比的非劣上限先讨论为 1.10 与 1.15，并使用预注册区间而非只有均值判断；若收益值得更高成本，必须在揭盲前另定效用函数和硬上限，不能事后豁免。P 的故障层恢复延迟单独报告，不能与正常任务混成平均数。

上述数值可因实际需求调整，但调整只能发生在确认结果揭盲前。若不满足预注册条件，结论就是“不通过/不确定”；不能以漂亮个例、下一动作偏好或更少 token 补票。

## 8. 安全、污染与“零泄漏证据”

### 8.1 必须控制的两种泄漏

**评估信息泄漏**：未来答案、隐藏 verifier、目标回执或锁定样本进入摘要、对象、检索索引、训练或调参。
**用户/作用域泄漏**：跨用户/项目/分支读取，删除/撤权后通过派生对象、软向量、日志、缓存或恢复数据重新暴露。

防范与证据：

1. 生成端、检索端、评分端使用隔离身份与存储；生成端无金标准路径和凭据。只给只读历史快照，不给整个任务包。
2. 在揭示未来答案前生成并封存摘要/对象；保存输入来源 manifest、时点/版本、调用出入站记录与访问审计。hash 只能证明绑定/完整性，不能证明摘要没有语义泄漏。
3. 数据按家族拆分；做精确与近重复检测，并人工抽查潜在语义重复。公开基准受预训练污染影响时单列，不作为唯一证据。
4. 加入秘密合成 canary：它们仅出现在另一 scope、已删来源或未来答案中；测试精确复现、语义透露及可推断答案。canary 本身不要出现在评测提示或日志展示中。
5. 注入来源文本要求忽略权限、伪造用户决定/回执、跨 scope 检索；验证摘要/对象不会洗白外部指令。
6. 删除/撤权前后探测普通检索、旧 checkpoint、缓存、导出、重启、备份恢复和服务端 handle；神经路径另测整体失效与获准来源重建。
7. 审计所有外发与工具请求；不得使用真实凭据或真实个人秘密作测试材料。未获授权的外发或泄漏立即隔离结果并停止该臂。

### 8.2 如何正确表述零泄漏

报告：“在 N 个预注册、相互独立或按聚类解释的泄漏挑战中观察到 0 次泄漏；已覆盖路径……；未覆盖路径……；单侧置信上界……”。不能写“已证明绝对零泄漏”。

在独立二项试验近似适用时，0/n 的单侧 95% 失效率上界可用约 `3/n` 作量级说明；实际报告应用精确方法，存在共享模板/家族依赖时按有效聚类解释，不能把大量相似样本伪装成极小风险。可建议 300 个独立挑战作为约 1% 上界量级的起点，但它既不证明零风险，也不代表足以接受某种安全风险。

任何确认的越权读取、删除后复活、重复外部副作用或 unknown 伪成功都属于硬停止事件；“统计上少见”不豁免修复与重验。

## 9. 停止、失败与缺失的处理

1. **立即安全停止**：出现越权、错误恢复授权、删除/撤权内容复活、重复副作用、unknown 被伪造为成功、跨 scope 泄漏。停止受影响臂，保存最小必要证据，分析根因；修复后新版本重新过 V1，并用新确认数据重验相关效益。
2. **资源停止**：到达用户批准的费用、GPU 时数、墙钟时间或存储硬上限即停止；未完成的确认实验报告“不确定/未完成”，不得悄悄加预算。
3. **功能无效停止**：确认性效应不满足门槛，或强摘要/检索同样达到收益且复杂度无额外价值，则停止该候选的生产接入。可保留研究结论，不为证明最初方案正确而反复换指标。
4. **完整纳入**：模型拒绝、格式错误、生成失败、预算耗尽、工具调用失误、真实运行崩溃均保留在分母，成本计入。不能删掉不利任务。
5. **基础设施例外**：只有与实验臂无关、符合预注册定义的外部故障才可标为基础设施异常。由盲态人员判定；同一任务所有臂成对重跑，最多重试次数预先冻结，并保留初次尝试与成本。不得只重跑输掉的一臂。
6. **无效与未知区别**：置信区间太宽是证据不足，不等于已证明无效；但同样不能准入。若后续扩样，先登记新阶段和资源授权，使用合理的顺序统计控制。

## 10. 神经软 token 后端独立门禁

### N0：身份、许可与可运行性评审

- 锁定作者仓库 SHA、SGLang revision、actor/tokenizer/encoder 权重 revision 与校验值、chat template、prefix/tool schema digest、模型许可、数据许可及依赖许可。
- 首轮优先只评估公开 Qwen 推理 checkpoint，不启动训练。官方部署建议的 Qwen 2×80GB GPU 与至少 100GB 磁盘只是资源规划起点，不是本方案已拥有硬件、满足峰值或批准支出的证明。
- GLM 单独申请硬件与推理实验，不能把 Qwen 硬件估计套用到 GLM。对公开 GLM 路径的摘要条件机制、1.24B/论文规模、128K/1M 对应关系列差异账；没有精确配方就仅称公开发行版评估。
- 普通只接受文本的远端 API 不能以占位符冒充软 token。若无向量注入能力、许可证或足够资源，结论为“该后端本阶段不可验证”，保持关闭。

### N1：运行时与存储合同

先用假数据验证绑定、跨 scope 隔离、崩溃恢复、旧 handle 拒绝、模型/prefix 变更失效、撤权/遗忘全链路失效与重建。必须证明失效向量不再被使用，不能只隐藏 UI 文本。无法定位受影响来源时整个 checkpoint 失效。

通过 N1 只表示可以进入神经效益实验，不能据此宣称保留了有效语义。

### N2：公平收益试验

- 所有比较固定同一个可注入向量的 actor、相同 SGLang/推理实现及精度、上下文窗口、工具、采样、缓存与并发策略。不得用更强 actor 的神经臂对较弱文本基线。
- 对比：基础摘要；同位置/资源预算文本补充；摘要＋检索；最佳已验证 T/P 方案；对应最佳方案＋软 token。若软 token 替代而非叠加某层，也单独声明；不得把不同比例混在一起。
- 重跑所用 actor 上的文本强基线。先前另一个模型的 T/P 成功不能直接移植为这次基线证据。
- 用开发集选择固定软槽/压缩预算；保留多次压缩、旧 frontier、来源失效、模型升级和负对照。若能在不越权的合成环境中做零向量/打乱向量消融，可作为机制诊断，不作为产品候选。
- 完成 V3/V4 同等级别的效益、误记、泄漏与总成本分析。只在引用 F1、下一动作偏好、单个演示或 token 费用上升/下降，不能放行。

### N3：独立实现决策

若收益不稳定、不能优于简单文本/检索、全成本或运行限制不合适、来源失效无法保证，则停在研究阶段。只有有用性、合同、安全、许可与资源都满足冻结要求，才进入具体实施决策并核对授权；缺失的实施范围另行确认，已明确批准的范围不重复确认。仍不能仅凭实验成功自动扩展到默认 Agent、Android 或生产数据。

重新训练、微调、新建持久凭据或长期 GPU 服务均为新的范围与资源请求，不被推理实验批准自动覆盖。

## 12. 实验交付与可审计证据包

每次实验至少交付：

1. 预注册版本与授权范围，实验开始/结束时间，所有候选/基线完整 SHA 和配置。
