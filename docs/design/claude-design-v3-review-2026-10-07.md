## 4. 新功能范围问题（需用户决定）
`Data Center` / `Desktop Data Center`（"Ontology 重做"）超出了你前几轮批准的范围，引入：
- **血缘**视图（对象/字段间数据来源）；
- **对象类型 / 查询接口 / 关系 / 动作 / 流程 视图**的完整浏览（其中动作、流程、门槛已批准；"血缘"和"查询接口"独立视图是新增）；
- **实例浏览器**：按对象类型浏览**真实实例**，沿关系跳转，敏感属性默认遮盖。

风险：实例浏览器是**第二个业务数据浏览入口**，与业务页面重复，并且读取真实数据——需要明确它读的是业务库还是投影、遮盖是否在数据层强制（不是只在 UI）、是否走 `ObjectRef` 与确认语义；这属于安全敏感的新功能，且当前冻结。血缘需要后端有字段级来源数据，现有 `schema_catalog` 是否支持我没核实。

**建议**：数据中心先实现 Folio 已有的三块（数据模型/对象详情、数据质量、AI 接入）+ 你批准的门槛/动作/流程；**血缘和实例浏览器单独立项，先出规格**。用户请决定：①实例浏览器要不要做；②血缘要不要做。
