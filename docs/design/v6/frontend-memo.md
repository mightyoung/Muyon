# 前端开发备忘录（设计稿 v6 的遗留问题）

日期：2026-10-07 · 用户决定：**设计稿到 v6 为止，不再请 Claude Design 返工**。v6 审阅发现的问题（见 [v6 审阅](../../reviews/2026-10-07-design-v6-review.md)），记在这里，在前端开发时直接实现正确的版本。设计稿只作视觉与交互参考；稿内的错误，以本备忘录和 ADR 为准。

## 总原则
1. **颜色只来自 token**：取值以 [`tokens.md`](tokens.md) 为准，`warn` / `warnbg` 已经定义。代码里不写死颜色，链接一律用 `acc`。稿里写死的 `#2458D3`，以及 Mobile、Desktop 里缺失的 `warn`，都不照抄。
2. **尺寸自适应**（UI 方案 §8 第 19 条）：控件高度由内容决定，48 只是最小点击区；圆形或方形按钮保持等宽等高。稿里 44×48 的椭圆、被撑大的状态栏和骨架块都不照抄。
3. **颜色语义**：红色表示失败、危险、外传；`warn` 表示需注意；绿色表示成功；待确认与选中同色系。
4. **对比度**：正文类配对 ≥ 4.5:1，深色模式下的危险按钮也要满足，由 UI-1a 的对比度测试兜底。深色下 `warn` 条和选中行的底色几乎没有色差，实现时给 `warn` 条加左侧实线，或者让图标明显可见，以便区分。
