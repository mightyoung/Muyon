# Muyon 设计 Token（手机 + 桌面）

> 对比度已按 WCAG 2.x 相对亮度公式用脚本实测（见下表）。正文与按钮目标 ≥ 4.5:1，标题级 ≥ 3:1。

## 颜色

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| bg | `#FCFCFC` | `#0A0A0A` | 页面底 |
| sf（面板） | `#FFFFFF` | `#141414` | 卡片、输入框、行 |
| sk（次级面） | `#F1F3F6` | `#1F1F1F` | 标题胶囊、分段底、占位 |
| rule | `#E2E6EC` | `#2B2B2B` | 分隔线、卡片描边 |
| rs（强描边） | `#C3CAD6` | `#3F3F3F` | 按钮/输入描边 |
| ink | `#111827` | `#F2F2F2` | 正文 |
| ink2 | `#4B5565` | `#C4C4C4` | 次要正文 |
| ink3 | `#636C7E` | `#9A9A9A` | 辅助说明、占位 |
| acc（主色） | `#2458D3` | `#F0A649`（琥珀） | 主按钮、选中、链接、角标 |
| onacc | `#FFFFFF` | `#0A0A0A` | 主色上的文字 |
| tint | `#E8EFFF` | `#3A2A12` | 选中底、待确认底 |
| deep | `#1B47C2` | `#F5C27A` | tint 上的文字与图标 |
| red / redbg | `#B8302A` / `#FDE8E6` | `#FF7A70` / `#3A1F1D` | 失败、危险、外传 |
| green / greenbg | `#17693F` / `#E6F4EC` | `#4CC38A` / `#17301F` | 成功 |
| warn / warnbg | `#8A5A00` / `#FFF1D6` | `#E8C547` / `#2E2A10` | 需注意、外部内容、授权过期、范围变化 |

规则：
- 红表示失败、危险、外传；
- `warn` 表示需注意，永远配 `warning` 图标和中文；
- 绿表示成功；
- 琥珀只作深色主色；
- 待确认与选中同色系（tint + deep）；
- 状态永远是图标 + 中文，不只靠颜色。

## 对比度（实测）

工具：本项目内 JS 脚本，按 WCAG 2.x 公式（sRGB 线性化 → 相对亮度 → (L1+0.05)/(L2+0.05)）逐对计算，非估算。

| 配对 | 浅色 | 深色 |
|---|---|---|
| ink / bg | 17.29 : 1 | 17.68 : 1 |
| ink2 / bg | 7.35 : 1 | 11.35 : 1 |
| ink3 / bg | 5.15 : 1 | 7.04 : 1 |
| ink3 / sk | 4.75 : 1 | 5.86 : 1 |
| onacc / acc | 6.16 : 1 | 9.67 : 1 |
| acc / bg | 6.00 : 1 | 9.67 : 1 |
| deep / tint | 6.68 : 1 | 8.47 : 1 |
| red / sf | 6.01 : 1 | 7.25 : 1 |
| red / redbg | 5.11 : 1 | 5.93 : 1 |
| green / sf | 6.71 : 1 | 8.32 : 1 |
| green / greenbg | 5.92 : 1 | 6.41 : 1 |
| warn / sf | 5.93 : 1 | 10.97 : 1 |
| warn / warnbg | 5.31 : 1 | 8.60 : 1 |
| warn / bg | 5.78 : 1 | 11.79 : 1 |

注：ink3 在 sk 上刚过 4.5，浅色下不要再用更浅的灰。

## 字体与字号

字体：Noto Sans SC（回退 PingFang SC）；等宽 Consolas / Menlo（接口名、散列、指纹）。
字号：11（徽标注脚）· 12（辅助）· 13（表格、说明）· 14（正文、按钮）· 15（列表标题）· 16（卡片标题）· 18（页内大标题）· 24（金额、桌面标题）· 40（配对码）。
字重：400 / 500 / 600。金额与数量用 `tabular-nums`，右对齐，保留两位小数。

## 圆角

8（业务表格、业务表单、PDF/预览框）· 12（输入框、小块）· 16（提示块、选项行）· 20 / 24（壳层卡片、分组列表）· 28（输入条）· 999（胶囊、圆形图标钮、开关）。
规则：业务页保持 8；大圆角只给壳层与平台页。

## 间距与尺寸

间距：4 · 8 · 12 · 16 · 20 · 24。页边距：手机 16，桌面内容区 24。
触达区：手机与桌面 ≥ 48×48（视觉可小于 48，点击区补足）。表头 42，表行 52，设置行 56–60，底栏 76。
桌面：图标轨 72 · 二级栏 240 · 助手栏 360 · 顶栏 56 · 收件箱抽屉 420 · 命令面板 560。
平板竖屏 820×1180；手机 390×844。

## 开关（Switch）

46×28，圆点 22；开：acc 底 + onacc 圆点；关：rs 底 + sf 圆点。

## 动效

| 动效 | 时长 | 减少动态效果时 |
|---|---|---|
| 按钮按下 / 悬停颜色 | 120 ms | 保留（无位移） |
| 抽屉 / 浮层滑入 | 200 ms ease-out | 改为直接出现 |
| 命令面板淡入 | 120 ms | 直接出现 |
| 进度“旋转”图标 | 连续 | 改为静态图标 + 文字“进行中” |
| 页面切换 | 200 ms 淡入 | 直接切换 |

未知进度一律不显示百分比。

## 焦点环

桌面所有可聚焦控件：`2px solid acc`，`outline-offset: 2px`（列表行内用 `-2px`）；主按钮上的焦点环改用 ink 色以保证对比。
