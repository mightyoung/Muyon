## 1. 结论
**v2 可以作为实现的视觉与交互规格，建议采纳。** 第二轮提示词的 A–I 九块全部有对应稿，并且做对了几件容易错的事（见 §2）。有 1 处功能缺失（数据质量）、几处需求未覆盖、几处文档与稿不一致，列在 §3–§5。

文件：`Muyon Mobile`（基准）· `Desktop`（桌面 7 屏 + 平板 + 1280 + 命令面板 + Tab 序号）· `Assistant Settings`（数据中心门槛、规则、SOUL、权限、记忆、模型）· `Research`（手机）· `Prototype+Inquiry` · `Exchange+System` · `Accessibility`，另有 `tokens.md`、`components.md`、`round2-notes.md`。

## 2. 做得对的（核对过）
- **决定都落实了**：底栏顺序工作台居中；深色所有主色/选中/待确认都用琥珀；红=失败/危险/警告，琥珀不表示警告；记忆在助手设置；界面里 **0 处 "Folio"**（7 个文件 grep 为 0）。
- **颜色纪律好**：7 个文件里不在 token 表里的颜色只有 页面外壳背景 `#E9ECF1`、手机边框 `#2A2A2A`、本体图 4 个分组色（沿用 Folio 的 `#677DA1/#5C8B86/#92734F/#84709B`）和原型占位灰，没有乱入的色。
- **对比度（我重算）**：所有文字配对 ≥4.5:1。例：浅 ink3/sk 4.8、deep/tint 6.7；深 onacc/acc 9.7、deep/tint 8.5、ink3/tint 4.9、red/redbg 5.9。稿里的估算与我的计算偏差在 0.5 以内，除 green/sf（深）稿写 9.5、我算 8.3，仍通过。
- **安全语义画对了**：确认卡固定字段；外传是「仅发送这一次」；"已送达≠已导入"；接纳后"尚未导入科研模块"另有"去导入"一步；撤销配对保留历史、禁止发送；本地取消写明"不会撤销对方设备上已开始的执行"；配对码不一致→"没有保存任何配对信息，也没有向对方发送内容"；规则里写入类"不可关闭"；权限开关"只收紧不放宽确认"；SOUL"固定安全规则不可覆盖"，且写明 SOUL 文本发往远程模型会入账到数据去向；备份恢复写明原数据保留位置；离线时"发送会排队，不会假装已送达"。
- **科研引用**：「无法唯一定位」画了态，且"未选择前不会标记为已核对"；证据支持程度与接纳状态**分成两个独立控件**，接纳需填理由与不确定性。
- **原型**：WebView 区域是灰色占位框，写明"导入内容原样显示，不套用壳样式"，并列出无网络/无文件访问/助手工具不可调用三个权限 chip；导入失败态是"包内含外部网络请求脚本"（符合受限 WebView 策略）。
- **状态矩阵**：文库、设备列表、规则、询价三类列表、反馈记录、科研任务/结果、桌面 6 个通用分区都有 载入/空/筛选无结果/失败/离线；失败文案都写了"数据未被改动 + 恢复路径"。
- **无障碍页**：320/390/430 与 200% 对照、底栏长按/悬停 tooltip、减少动态效果表、触达区 ≥48、桌面 2px 焦点环、Tab 序号、⌘K。

## 3. 缺口与风险（需决定或补稿）
| # | 问题 | 说明 | 建议 |
|---|---|---|---|
| G1 | **Folio 原有「数据质量」与「AI 接入」页面没有了** | v2 的数据中心是 本体图/动作/流程/AI 知识（发布门槛）。现有应用的数据中心有三块：数据模型、**数据质量**（按领域列待处理检查：待询价预算行、待核对条款、物料参数缺失等，进入现有预览流程）、AI 接入（本地查询工具与 MCP）。数据质量是**业务功能**，被替换后无处可去；AI 接入大概率并入"接口与 MCP"但稿没说 | 向 Claude Design 补一屏「数据质量」（可放在数据中心第 5 个标签或询价插件内），并确认 AI 接入并入「接口与工具」 |
| G2 | **图标集** | 稿用 Google **Material Symbols Outlined**（CDN 字体）。应用现用 Folio 自制 102 枚业务图标 + Flutter 内置 Material Icons；Symbols 的"实心选中"需要 variable font 的 FILL 轴，Flutter 内置 `Icons.*` 没有。三选一：① 打包 Material Symbols 字体（需新增资产/依赖，需 leader 批准）；② 用内置 `Icons.*` 的 outlined/filled 成对图标（风格略有差异）；③ 继续用 Folio 自制图标并补缺 | 推荐②（零依赖，选中态用 filled 变体）；若要求与稿完全一致再选① |
| G3 | **字体** | 稿从 Google Fonts CDN 加载。应用必须离线，Noto Sans SC 已打包（`assets/fonts`），无需处理，只提醒实现者不得引入 CDN | 无 |
| G4 | **非文本对比度** | 控件描边 `rs` 对页面底：浅色 1.6:1、深色 1.9:1，低于 WCAG 非文本 3:1（输入框边界、开关"关"状态底色）。这是 Folio 基线就有的取舍，稿沿用 | 若要达标：输入框边框与开关"关"态加深到 ≥3:1，或输入框加底色区分；先记为已知偏差 |
| G5 | 桌面除 报价/文库+阅读器/写作 外，**项目、供应商、物料、任务、结果 用同一套"表格 + 详情"通用页** | 稿自述；各自专属布局（预算行编辑、参数表、任务时间线）桌面版缺 | 可接受作为首版：实现用通用 `DataTable + MasterDetail`，专属布局后续按手机稿扩展 |
| G6 | **工作区**（新建工作区、切换、绑定模块项目、首次导入/恢复未完成导入）只有顶栏"个人工作区 ▾"一个入口 | 现有应用有"新建工作区""导入研究目录/ZIP""恢复未完成导入""接收任务包"四个入口和工作区-模块绑定流程，稿未画 | 补稿：工作区切换面板 + 新建 + 导入向导（含中断恢复） |
| G7 | **研究包完整导入/导出**（目录、ZIP、结果包、任务包）在科研里只见「导入论文」 | 需求的"完整研究包交换"、"重复导入/并发分叉处理"没画 | 补稿 |
| G8 | **公司资料中心**（连接设置、"发布到公司资料"前列出随同发布每条记录、联系人需勾选、含项目时提示带上客户与合同金额）只有卡片 | 这是外传确认的一类，要走统一确认卡 | 补稿（复用确认卡，列出记录清单） |
| G9 | **离线工具模式**的实际界面（选工具 + JSON 参数 + 确认）只有一个开关 | 现有助手页有此模式 | 补稿，或确认只保留开关并把选工具放进命令面板 |
| G10 | **询价表单**：只有通用新建/编辑 + 校验失败；报价表单（金额、税率、有效期、来源、附件）、智能导入预览、技术要求与物料参数的比对结果（满足/不满足/未知）没画 | 业务核心流 | 补稿，优先"报价表单 + 导入预览" |

## 4. 稿与自述文档的不一致（不影响采纳，但别被 notes 误导）
- `round2-notes.md` 说"记忆、模型列表的空与失败态""敏感属性剔除计数"未做，但 `Assistant Settings` 里**已有** memFail/memEmpty/modelFail/modelEmpty 与"本次摘要剔除 N 项"。以稿为准。
- `components.md` 的"确认卡圆角 20 / 工具调用卡 24"与 `tokens.md` 的圆角表一致；本体图尺寸写"358×330（手机）"，桌面版未给。
- `Muyon Mobile.dc.html` 内的状态机是演示用；其中本体图坐标、示例规则/评测都是**写死的示意数据**，不是接口契约。

## 5. 对任务拆分的影响（给 leader）
- **UI-1**：token 以 `tokens.md` 为准（深色琥珀 `#F0A649 / deep #F5C27A / tint #3A2A12 / onacc #0A0A0A`）；组件清单以 `components.md` 为准；token 命名建议 `accent/accentDeep/accentTint/onAccent`，**不要再叫 amber**（避免旧"警告"含义残留）。图标集先按 G2 决定。
- **UI-2/3/4/5/6/7**：直接按对应 `.dc.html`：Mobile（壳、工作台、助手、收件箱、设置）、Desktop（桌面壳、命令面板、抽屉）、Exchange+System（数据交换、存储、MCP、工具）。
- **UI-8/9（插件接入）**：Research、Prototype+Inquiry 分别是科研、原型外围、询价的页面规格；原型 WebView 保持占位。
- **新功能 N1–N4**：UI 稿齐了（数据中心门槛、规则、SOUL、权限）；**仍然先写后端规格再实现**（见 v1 审阅 §8）。UI 实现要等后端，不能先用写死数据上线。
