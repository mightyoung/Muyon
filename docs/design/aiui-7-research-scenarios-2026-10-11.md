# AIUI-7 科研场景对话界面设计（CR-4，ChatGPT 6 Pro）

状态：**设计稿，D1～D7 已由用户采纳（全部按推荐，见 ADR-0001 末尾 2026-10-11 条）** · 依据固定在 `86525cd135f0e8ac98ac2ab2abaee6a59c93f156`（CR-2 对照用 `814b6ce`）· 只读静态设计，未改代码、未运行测试 · 原稿由用户转交，leader A 整理入库（保留全部结论、边界、验收编号与待决事项；代码引用以原稿为准，下文只保留关键位置）。

## 一页结论
- 形态：**对话提出研究目的 → 引用卡展示依据 → 工作区完成深度操作**。桌面对话与工作区并排；手机进全屏阅读器或结果页，返回保留对话位置。长文阅读、划词、复杂关系图、导入与设备交换留在原页面。
- 首批 8 个目的：目标概览、本地文献查找、运行评估、接纳运行、挂接提纲、论文与主张、运行对比、段落编辑（REG-3c 在途）。GROK-7 的「修改项目问题 / 下一步」后置。
- 当前接入条件：科研已登记 3 个读工具、4 个写工具；但默认规划关闭，现有规划源只提取成功回执中的标量，没有科研需要的完整来源、集合、计算与业务动作映射。「工具已有」只表示业务基础，不代表 AIUI-7 已交付。
- 三项语义必须分开呈现：引用卡区分「存在引用关系 / 原句能定位 / 材料支持结论」；阅读器区分「打开文档 / 跳到某页 / 精确高亮」；运行结果区分「执行状态 / 接纳状态 / 原始结论 / 研究评估」，差值不自动变成科学判断。
- 敏感度沿用已定 `none`；远程模型仍按端点授权，含外部内容的任务写入与外传逐次确认。

## 1. 首批目的（问句为文案模板；快照字段为宿主适配要求）
动作三类：本地（展开、筛选、选择、编辑草稿、打开工作区，不改记录）；业务（已登记写工具，确认后执行，以真实回执更新）；语义（交回助手，需要模型时照常经宿主模型请求）。

### 共用快照与公式
- 每张卡至少需要：任务与项目范围、完整对象引用、修订或摘要、事实状态、来源引用、集合是否完整；写卡另需宿主生成的草稿版本、操作引用、允许动作。模型只能引用宿主给的 ID。
- 拟登记公式（**目前都未登记**；公式注册器只有 5 类既有公式，重算适配器拒绝 library-2，均为接入前置）：`research.entry_count_by_kind`、`task_count`（按任务取最高修订计数）、`artifact_count`、`run_metric_delta`（A−B，可为负）、`run_metric_pct_change`（(A−B)/B，「相对变化率」）、`evidence_count_for_section`、`section_support_counts`、`accepted_run_count`、`claim_link_count`（只计已解析 ID+修订）。
- 规则：缺失、未读取、截断与确认的零值分别表示；差值要求两侧有限数值，非数值保留原值；基线为零时相对变化率「不可计算」；单位或定义不一致时只展示原值；计算带快照版本，换基线后不展示错配旧值。

## 2. 三张核心卡 / 工作区
### 2.1 引用卡
- 区域：结论（标明来自记录还是助手分析）、关系（方向、类型、修订）、判断边界（证据性质、支持的表述、不支持的结论、适用范围）、原文（短引句、文档、物理页、来源版本、定位状态）、操作（本地入口；写作关联另走确认）。
- 关系规则：`claims.paper_id+paper_rev` 只表示引用，不证明支持；`conflicts` 只表示记录声明了冲突；笔记 `entry_id`、提纲 `evidence_id` 不升级为支持关系；缺修订、未导入、身份重复显示「引用未解析」，不自动换最新修订。
- 来源：持久 `SourceRef` 与界面 `SourceSpanRef` 由宿主核验映射，不能用文件路径或模型引句冒充。定位状态：exact（阅读器实际跳转并绘制后才显示「已高亮」）、uniqueText、pageOnly、ambiguous（多处 / 零处分开表述）、来源缺失或换版、范围失效（禁止继续取材）。
- 可写边界：只读原句、修订、关系、定位、摘要；可对已开放的 entry/run 提出「用于写作」关联；不在卡上新建支持边、改论文绑定、改主张 JSON、把普通批注伪装成结构化精读证据。

### 2.2 阅读器工作区
- 桌面并排、手机全屏；返回原回答卡片位置；阅读页、滚动、草稿分别保存，切换不自动提交；不新增第二个科研助手会话；选区不自动进入模型上下文。
- 留在原页面：PDF 翻页缩放选择、原句高亮与匹配核查、长文阅读、结构化精读笔记、关系图布局、冲突处理、批量绑定扫描、导入与设备交换。
- 两种入口：「打开文档」只绑定文档；「核对这处引用」绑定完整来源锚点，打开前重查摘要与范围，物理页从 1 显示。canonical package 文档暂无 ReaderPage 适配器时明确说明，不假装打开原文。
- 普通批注 vs 精读证据：`research.save_note` 只收 `document_id、locator、text`；对话只保存普通批注，完整精读证据进阅读器完成；不把页码引句拼进正文冒充结构化保存。

### 2.3 结果对比
- 结构：对齐条件（项目、任务、任务修订、口径完整性）、基线 B 与本次 A、指标表（名、单位、B、A、A−B、相对变化率、状态）、原始结论与研究评估分开、依据展开、后续动作。
- 规则：默认只比同任务同修订；基线显式可见；本地改条件不调模型，由宿主重算，完成前显示等待；保留原值不补零；正负差不自动染成改善或退步，不宣称显著或支持假设；解释与执行分开。
- 可写只限已登记的评估与接纳；不改指标原值、执行状态、任务规格或历史修订。运行的 `revisionRef` 对应任务修订，不标成「运行修订号」。

## 3. 「只用文字」档
关闭模型生成的布局与可视化，保留文字、来源入口、固定页面与必要的宿主确认。8 个目的各有文字写法（列已保存事实、助手建议、编号候选、「证据 → 段落」、逐指标原值与宿主差值等）并由固定页面或宿主确认承接。三个等价条件：**事实等价**（未知状态同样保留，文字不代替宿主计算）、**操作等价**（自然语言「确认」不能变成审批票据）、**回执等价**（只按真实回执报告结果，恢复会话不重放写入）。

## 4. 与询价写卡（CR-2）的关系
- 一致：结构由宿主生成；已保存事实与建议分开；只提交开放字段；提交前与执行时双重校验；确认绑定版本；成功只认回执；流式边界一致；外部内容不出现放行按钮。共用状态：草稿、校验中、待确认、执行中、成功、失败、冲突、已撤销、执行结果待核实。
- 四种卡映射：新建（普通批注，后续段落）、编辑（运行评估、后续段落）、关联（条目或已接纳运行挂提纲）、批量（当前科研无批量工具，首版只给逐项待处理清单，不把循环单项调用包装成批量）。
- 必须不同：敏感度 `none` 不照搬询价遮盖；任务修订、运行摘要、段落摘要、文档字节摘要各用真实机制，不伪造统一 `expected_version`；引用 / 笔记关联 / 写作关联 / 支持 / 反驳分别呈现；运行评估枚举与段落支持程度枚举不混用；具名流程不拼通用 CRUD；不照搬「最低价 / 最优」标签；引用固定到来源字节与修订。远程模型规则不因 `none` 放宽。

## 5. 验收（拒绝路径，拟定）
- 范围、流式与执行：A01 未明确目标不推断执行；A02 不沿关系读取范围外邻居；A03 不存在的 fact/source/computed ID 拒绝并降级；A04 流中自报路由、公式结果、权限、操作内容拒绝；A05 无有效结束、取消或最终校验失败时预览动作不可执行；A06 公式未登记 / 重算不可用 / 版本不匹配不展示差值；A07 写工具或业务映射缺失时无可执行提交；A08 确认后对象或草稿变化拒绝旧提交；A09 外部内容不出现「始终允许」，缺端点授权不发送；A10 重复点击、迟到回调、会话恢复不重复写入，回执未知显示待核实。
- 科研事实与来源：R01 截断集合不显示总数；R02 未索引或失效不报「零命中」；R03 标题相似或模型认为相关不当作已保存关系；R04 未解析保留状态不取最新修订；R05 摘要不符或换版不替代旧来源；R06 零匹配、多匹配、缺几何不显示「已高亮」；R07 无可信选区交接不声称保存结构化证据；R08 未开放的 note 元数据不静默丢弃后报成功。
- 运行与写作：W01 任务或修订不一致不进默认对比；W02 无可靠顺序不擅定「上次」；W03 缺失或口径不齐不补零不强转；W04 基线为零不算变化率；W05 未结束或不可区分却选 supporting/refuting 拒绝；W06 接纳不得改执行状态、结论或段落支持程度；W07 同名段落不静默选第一个，新建副作用确认前显示；W08 当前 `add_outline` 不收 note、section_id、批量；W09 REG-3c 未登记前不启用段落编辑提交；W10 切到「只用文字」不丢未知状态、来源版本、确认与回执。

## 7. 交给实现的前置条件
1. 科研快照适配：完整运行信息、来源、领域关系、段落候选、集合完整性，不用嵌套 `.data` 充当全部事实。
2. 公式与本地重算：登记科研公式并接通 library-2；之前对比只显示原值与固定页面。
3. 来源导航：`SourceRef` → 快照来源 → 阅读器定位器的可信路径；明确不支持的文档类型。
4. 业务动作映射：四个已有科研写工具绑定宿主操作、草稿、确认、回执；REG-3c 按真实声明逐项增加。
5. 跨模式验收：交互、纯文字、固定页面三种方式使用相同事实、权限与成功标准。
