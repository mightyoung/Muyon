## 提示词

第三版（v3）基本采纳。本轮做三件事：**修正 v3 的错误**、**把数据中心统一成一套**（并补上血缘与实例浏览器）、**补 Folio 仍缺的 4 个页面**。规则不变：询价插件的业务功能与页面以 **Folio** 为准，外观按 v2/v3 token 与组件；**手机框内的界面里不得出现 "Folio" 字样**（给设计者的备注只能放在手机框外的说明区）。沿用已定决定：底栏顺序、深色用琥珀代替蓝、红色=失败/危险/警告、记忆在助手设置、内置 Material 图标线性/实心成对、点击区 ≥48×48、所有数字标"示意数据"。

### A. 修正 v3 的错误
1. `Muyon Prototype+Inquiry.dc.html`：
   - **删除其中的询价回收站页**（含"永久删除 / 确认永久删除"按钮）。回收站只保留 `Muyon Inquiry Spec+Catalog` 里的「已删除的记录」版本（无保留期、无永久删除、入口 设置 › 已删除的记录）。
   - 该文件里**询价部分**（比价、预算、项目详情等）已被 `Inquiry Core` / `Inquiry Spec+Catalog` 取代：请删除这些重复页，只保留**原型插件外围**（原型列表、版本评审、反馈记录、导入、受限 WebView 外框），并把文件改名为 `Muyon Prototype.dc.html`。
   - 比价页图注里的"· 按 Folio"是泄漏进界面的备注，删除（该页随上一条一并删除）。
2. `round3-notes.md` 与实际不符：重写为 `round4-notes.md`，只写**当前真实状态**，不要沿用"仍未覆盖"里已完成的条目。
3. 所有新稿与旧稿：控件**点击区 ≥48×48**。视觉高度可以是 44，但要在稿里标出点击区（例如不可见的 padding），并在 `components.md` 写明这条规则。

### B. 数据中心：统一成唯一一套
目前有三套：`Assistant Settings` 里的数据中心门槛页、`Data+Exchange+Hub` 与 `Desktop Data` 里的"简版"、`Data Center`（手机）+`Desktop Data Center`（桌面）的 Ontology 重做。**以 `Data Center` / `Desktop Data Center` 为唯一规格**：
- 删除另外两处的数据中心页面（`Assistant Settings` 里的数据中心页、`Data+Exchange+Hub` 与 `Desktop Data` 里的数据中心简版），在原位置只留一个入口："设置 › 数据中心"。把它们里面**独有的内容**（完整的"数据质量"、"AI 接入"、注册检查与"去哪里改"、同步知识库的进行/成功/失败/取消/回滚状态、示例问法评测、敏感属性标记与"摘要中已剔除 N 项"）**并入**唯一规格对应的视图。
- 唯一规格里每个视图都要有**专属画面**，不要共用一个通用列表：概览 · 本体图 · 对象类型 · 关系 · 动作 · 查询接口 · 流程 · **血缘** · **数据质量** · **AI 知识（发布门槛）** · **AI 接入** · 对象详情 · **实例浏览器**。手机与桌面各一套。
- 保留 Folio 的三块：数据模型（对象详情：同类引用 / 引用了 / 被引用于 / 必填 / 字段 / 类型 / 说明）、数据质量、AI 接入。
- **数据质量（按 Folio）**：默认显示"待处理"，可切"全部"；按领域分组（项目与技术要求、物料参数、报价、供应商与数据一致性）；每条结果带**单位**，不同单位不相加（组、条报价、行预算、条条款、项需求、家供应商、项物料、项冲突）；参数类问题进"预览补全"后确认写入；其他问题"打开完整列表"；无问题"没有发现需要处理的问题"；物料参数批量工具放在"物料参数"分组内。**加入物料参数迁移**（Folio 的 param_migration：迁移前预览、确认后写入、可中断恢复、完成/失败）。
- **AI 知识（发布门槛）**：6 项检查、每项失败的"去哪里改"、示例问法评测（通过/未命中/重跑）、同步到助手知识库（进行中/成功/失败/已取消/回滚）、敏感属性剔除数。
- **原型插件在数据中心里的表现（用户决定：原型用 WebView 展示，其内部数据先不管）**：原型卡片显示中性状态"不适用 · 内容为 WebView 导入，内部数据本期不纳入数据中心"，不画 6 项检查，也**不显示为红色"不可发布"**；原型没有对象类型、实例、血缘。
- 每个视图补齐状态：载入中、空、筛选无结果、失败（写原因 + 恢复路径 + 重试）、离线。

### C. 血缘与实例浏览器（用户已决定要做；请把安全约束画出来）
**C1 血缘**（只展示系统**真实会记录**的来源，不要虚构数据流）：
- 对象级：该对象的 来源（手工录入 / 导入的文件或交换文件 / 智能导入 / 设备交换 / 公司资料）→ 变更记录（哪台设备、何时、改了什么字段，沿用 Folio 的"变更记录"）→ 被谁引用（关系）→ 是否已发布到公司资料/导出过。
- 属性级：有来源证据的属性显示"来源原文/来源附件"（如采购来源"网页资料尚待核实"，可另存原始来源及字段证据）。
- 视图：时间线 + 一张简图（来源 → 对象 → 被引用方）；"没有记录来源"要明确写，不要补全。
- 状态：载入、空（"没有来源记录"）、失败、跨设备冲突时指向"修改冲突"页。
**C2 实例浏览器**（只读、安全敏感）：
- 入口：数据中心 › 对象类型 › 某类型 › "浏览实例"；列表：搜索、按类型筛选、分页或虚拟滚动（数据量大时不卡）、排序；列表**默认不显示敏感属性的值**。
- 实例详情：属性表、关联对象（沿关系，每一跳标出所用的查询接口名）、"在业务页面打开"、"针对此对象提问"。**不提供编辑、删除、导出、复制整行**；回收站中的对象不出现。
- **敏感属性**（含税总价、客户、预算、联系人电话等，由插件注册时标记）：默认遮盖为 `••••`，旁边「显示」按钮；点击后只对**该值**临时显示，离开页面或 30 秒后自动重新遮盖；被遮盖的值**不可复制**；任何情况下敏感值**不进入助手上下文、不进入知识库摘要、不出现在截图/任务切换预览里**（页面进入后台时整体遮盖）。画出这些状态：遮盖、已显示（倒计时）、已自动重新遮盖、"此属性被标记为敏感"的说明。
- 与助手的关系：实例浏览器是**人看**的入口，不是助手的数据源；页面里写明"助手只通过已注册的查询接口读取，并受'助手权限'限制"。
- 状态：载入、空类型（"还没有实例"）、筛选无结果、失败、对象已被删除（"这个对象已被删除，可在 设置 › 已删除的记录 恢复"）、无权限/被关闭。

### D. 补 Folio 仍缺的 4 个页面（手机 + 桌面）
1. **询价概览（工作台）**：搜索（项目、供应商或报价）；快捷：录报价、智能导入、新建项目；待办分组：修改冲突（"确认保留哪一个值之前，这些字段按最后导入的值显示"）、询价单（今天截止 / 已逾期 / 未设截止日）、待询价的预算行、30 天内到期的报价（"…到期"）；"今天没有要处理的事"空态；失败态。它是询价插件的首页分区（放在业务插件功能卡片的第一张"概览"）。
2. **AI 任务**（询价插件内的页面，也可从收件箱"运行"进入）：任务类型 = 问数据 / 智能导入报价 / 按清单建项目 / 读取技术条款 / 提取技术参数；状态 = 执行中或上次执行中断 / 待核对确认 / 已完成 / 原始数据已变化 / 已停止 / 已暂停可继续 / 执行未完成 / 等待继续；操作 = 继续（问数据→"继续问数据"、读条款→"继续读取条款"）、删除任务记录；说明"这类任务暂不支持从此处继续"和"原条款已变化或条款 AI 已关闭，请回到需求项检查后重新开始"；"暂无 AI 任务"空态。
3. **物料参数迁移**：已并入 B 的数据质量；单独画迁移向导（范围、预览、确认、进度未知不显示百分比、中断后恢复、完成/失败）。
4. **助手历史回答**：旧对话里没有保留依据的回答标"未保留依据"；有依据的保留"依据 · N 条记录 · 查看核验"。在 AI 助手对话页和对话抽屉里各画一次。
