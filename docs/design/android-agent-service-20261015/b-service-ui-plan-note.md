Before actual controller exists, local transport envelope is TransportInitializing/Unavailable **without Rust epoch/revision**. Only actual controller connect supplies AgentReplyMeta.

- AIDL methods map to actual generated camelCase equivalents of native `connect/start_run/status/current/lookup/set_visibility/release_client/cancel/close`. Platform method submit means start_run. No additional result method is necessary: lookup supplies result semantics. **client_gone and await_settled remain Service-only, never AIDL methods.** No streaming callback/oneway queue.

Same current observe key+same revision requires identical authoritative snapshot; do not compare status and control-ACK wrappers as equal snapshots.

At most1Rustworker+1Servicewaiter; coalesce any required follow-up settlement request rather than accumulating waiters. No file I/O/join on Binder/main; no long AIDL run. 2. Local connection/lease/display generation capture rejects late replies after disconnect/rebind/lease change/panel detach. Wrong protocol/build/epoch/run/request/variant rejects. Current finds outstanding identity after local request loss; historical lookup never replaces a new active run.
3. Same-epoch lower server revision ignored; duplicate equal-revision same authoritative snapshot accepted; conflicting equal-revision same observe key refuses without erasing known terminal. Higher-revision Running cannot regress an already authoritative terminal for that run. Different RPC ACK and status envelopes are not spuriously compared. 4. Optional task/attempt pair, durable identity versus Queued, terminal summary identity, receipt outcome preservation and closed enum/field bounds. Transport exception/timeout/NotRunning/Unresolved do not prove NotStarted, Cancelled, zero read, Failed or Closed. No missing value default0/success.
5. App visibility uses activity identity set/count, not unbalanced increments: initial client invisible; first real visible lease sends visibility; one of multiple activities stopping keeps visible; last stops sends false with checked monotonically increasing generation. Rotation false→true preserves request and cannot clear a stop/resume. Panel detach only display. Old generation/conflict/repeated lifecycle events cannot undo newer visibility/release.
6. Checked nonwrapping counters; terminal identity retained during transport loss and lookup recovery; process UI memory loss calls connect/current first. Local drafts/focus/scroll/notes/preferences remain byte/field-equivalent through all events (existing merge regressions retained).
7. Bounded client scheduling: max1status in-flight; blocked status/submit does not block independent cancel/close/visibility/release channel; no thread-per-poll/unbounded queue. Deterministic latches/fake executors, no sleeps as ordering oracle. Local timeout does not assert Binder call interruption.
