## 提示词

第二版（v2）我们已采纳。本轮补齐缺口，并**纠正与现有产品不一致的地方**。沿用 v2 的 token、组件、深浅色、状态写法，新稿仍用 `.dc.html`，新增文件，不要改动已有稿，除非列在「对已有稿的修正」里。

### 0. 最重要的规则：询价插件以 Folio 为准
沐阳里的「询价」插件由已上线的应用 **Folio**（原 software-cost-calculator）整体迁入。**业务功能、业务页面、字段、列、状态、流程、口径、导出导入与确认撤销语义，若与你的稿有出入，一律以下面「Folio 事实」为准**；外观（颜色、圆角、字体、图标）、导航壳、响应式、载入/空/失败状态组件仍按 v2。拿不准时按 Folio，并在稿里标「按 Folio」。不要发明 Folio 没有的业务功能（例如"30 天回收"、"永久删除"）。

### 1. 沿用的已定决定（同第二轮，不变）
底栏顺序 AI 助手 · 业务插件 · 工作台 · 数据交换 · 设置，纯图标；深色用琥珀代替蓝；红=失败/危险/警告；记忆在助手设置；无 "Folio" 字样（界面里叫"询价"）；业务页 8px 圆角、金额右对齐、两位小数；图标用 Material 内置图标的**线性/实心成对**（选中用实心），**不要依赖 Material Symbols 的可变字体 FILL 轴**；安全语义同前（逐次确认、已送达≠已导入、本地取消不冒称远端撤销、模型回答与资料不授予权限）；所有数字标"示意数据"。

### 2. 本轮要补的屏（手机为主；标 ★ 的另出桌面版）

**A. 询价核心流程**
1. ★ **报价表单**（新建/编辑，长表单分组）：
   - 报价内容：供应商、物料、项目（可空=通用报价）、单价、单位、**价格口径**（含税 / 不含税 / 未知·不参与比价；含税与不含税时显示税率 %）、**价格性质**（正式报价·书面报价单等 / 口头询价·仅参考，不用于预算 / 网上或第三方参考价·不用于预算）、**阶梯价**（"需求数量达到某档时按该档单价计入预算和比价"；每档数量+单价都要填；添加一档/删除这一档；未填完整时提示"阶梯价的数量和单价都要填写，不用的档请删除"）、起订量、交期（天）、报价单位（单位换算）。
   - 询价信息：询价人、联系人（可选；该供应商没有联系人时提示"可在'供应商'中添加"）、询价日期、询价地点、报价范围。
   - 附加费用（合计，如运费）、质保（月）。
   - 有效期与备注：报价日期、有效期至、备注。
   - 底部操作：保存报价；次要：取消；菜单里：发布到公司资料、撤销定标（已定标时）、删除报价（确认）。
   - 状态：校验失败、保存失败（已填内容保留）、编辑已定标报价的提示。
2. ★ **报价列表**：列＝物料/型号、供应商、项目（无则"通用报价"）、单价、报价日期、有效期至、状态。**状态徽标**（图标+中文）：已定标 · 可用 · 已过期 · 超 90 天未更新 · 口头或参考价 · 含税口径未知 · 报价日期在未来 · 未填报价日期 · 供应商已删除 · 供应商已停用。搜索（物料、型号、供应商、拼音首字母）；筛选：全部 / 口头参考 / 项目。**报价时效提醒**入口（即将到期、长期未更新两类，每类最多显示最早 50 条，"暂无即将到期的报价"空态，"时效提醒暂不可用，点击重试"失败态）。操作：智能导入、导入报价表、导出报价表、下载空模板（报价模板.xlsx）、新建报价；批选后：导出选中、删除。导入时若发现"本机在导出后又改过这条报价"，要有**覆盖警告**。
3. ★ **比价（纠正 v2）**：v2 写了"原始报价金额，不换算"，这不符合 Folio。Folio 的比价表列＝供应商、**比较价**（按价格口径换算，标"含换算"）、报价日期、有效期至、起订、交期、质保、价格包含、状态。状态/标记：最低有效价、已定标、已过期、口头或参考价、含税口径未知、**口径不同**、已失效或未达起订量、范围未说明、供应商已删除/已停用。请同时显示**原始报价**与**比较价**，换算过的要有标记；不参与"最低有效价"的行说明原因。空态："这个物料还没有报价 · 录入或导入报价后即可比价"。每行有「定标」入口。
4. **定标对话框**：成交单价（"谈判后的价格；默认等于报价"，须大于 0，错误提示"成交单价应为大于 0 的数字"）、定标理由（占位例："含税价最低、交期最短、含安装调试"）、说明"确认后，预算中这一行的成本单价会改为成交单价"；确认定标/取消；已定标后「撤销定标」。
5. ★ **询价单**：头部：项目、回复截止日（可修改；"已逾期"标记）、状态（进行中 / 已结束，可"标记为已结束 / 重新打开"）。主体：物料/数量 × 每家供应商的报价单元格（最低、口径不同、已失效或未达起订量、范围未说明）。操作：复制询价消息（发微信或邮件）、导出询价表（发给供应商）、导入供应商回填的表（含导入预览与失败）、录入报价（单元格弹窗）、定标/撤销定标、删除（可撤销）。定标成功提示"已定标，预算已更新"。
6. **智能导入报价**（含"按清单建项目"）：入口页 → 粘贴信息 或 选 Excel → "正在分析报价信息…"（进度未知，可停止；中断后可恢复）→ **核对页**：逐字段显示**原文**并可修改；选择"已有项目 / 新建项目"（项目编号、名称）、询价人、"同时加入项目成本预算"；每条可能的警告："没有供应商，只登记物料""没有单价，只登记物料""含税口径未知"；"仅登记物料；不导入供应商，不保存报价"选项 → 导入。固定提示："确认前不会写入任何数据。只会发送你粘贴的内容，不会发送本机数据。" 外发给模型的那一步要出现**统一确认卡**（做什么/对谁/发送内容/摘要散列/仅发送这一次）。失败："没有识别出产品报价，检查内容后重试"。

**B. 项目、预算、技术要求**
7. ★ **项目表单**：项目编号、项目名称、客户、合同金额、加价率 %、合同号、负责人、部门、状态、类型（未指定 / 市场订单 / 内部研发）、级别、价格口径（含税/不含税）、币种（CNY 人民币 / USD 美元 / EUR 欧元）；新建时可选"复制已有项目的成本清单（可选）/不复制，从空白开始"。删除确认文案："项目和它的成本预算行会从列表中移除，报价记录保留。删除后可以立即撤销，也可以在 设置 › 已删除的记录 中恢复；交换文件导入到其他设备后，那里也会删除。"
8. ★ **项目详情（补全）**：头部四个数：**合同金额、成本合计、对外报价、毛利**（合同金额未填显示"未填"）；页签：**成本预算 / 询价单 / 技术要求 / 报价记录 / 变更记录**；更多菜单：导入报价或粘贴 Excel、按最优价刷新、从清单生成新项目、推送到局域网设备、导出（项目报价单·给客户 Excel/PDF；成本预算表·内部 Excel/PDF；待询价清单·给供应商）、删除项目。PDF 缺中文字体时提示"请改用 Excel 导出"。
9. ★ **成本预算表**：列＝名称/型号、数量、单位、成本单价、成本金额、对外金额、提示；**提示类**：有更低报价 · 报价已失效 · 未达起订量 · 待询价（每种图标+中文）；合计行：成本合计、毛利；空态"这个项目还没有物料 · 从物料库添加，并自动带出最低有效报价；库里没有的可以先作为待询价添加"，主按钮「添加物料」；"刷新价格"（按最优价刷新）的预览与确认。
10. ★ **技术要求（Folio 里最复杂的一块，请完整画）**：
    - 技术要求列表（每份：名称、来源、需求项数、已核对进度）与**导入**（粘贴/文件 → 识别 → 预览）。
    - **单份技术要求页**：需求项列表（设备类别，可改；类别待定；已定选标记）。选中需求项后右侧/下级：
      - **设备类别**选择（提示"改类别后，未核对的条款会按新类别重新识别"）。
      - **条款**：逐条核对（标为已核对 / 全部确认）、**★ 实质性条款**（"不满足即排除；都不标时，所有条件都按必须满足处理"）、文字条款（"文字条款，需人工判断"）、添加/修改条件。
      - **用 AI 读未识别的条款**（可停止；"AI 没有读出新的条件"；"条款已修改，本次 AI 结果未覆盖你的修改，请重新解析"；发给模型前走确认卡）。
      - **匹配与定选**：先选类别才能匹配；候选物料与逐条满足/不满足/未知；定选/取消定选。
      - **供应商响应**：每条填写具体内容（"不写'满足'"），偏离标记，保存响应。
    - 导出：技术偏离表（Excel/PDF）、供应商偏离表（Excel）；"加入项目预算（待询价）"；"需求项都已在项目预算里"；删除（可撤销）。
    - **按要求找物料**页：设备类别 + 添加条件，"至少填写一个条件的值，就会列出候选物料"；★ 提示文案同上。
    - 所有状态：载入、空（没有需求项/导入时没有识别出设备）、失败、条款被修改后的冲突提示。

**C. 供应商与物料（补全，纠正 v2）**
11. **供应商**：列表（搜索名称、别名或拼音首字母；可批选导出/删除；导入/导出）；表单字段：名称、别名（多个用逗号分隔）、主营类别（逗号分隔）、地址、备注、**评价说明**（例"交货准时、售后响应慢"）、**停用开关**（说明"停用后，这家的报价不再算有效报价，不参与最低价，也不会被自动带入预算"）；保存后才能添加联系人；详情：联系人（添加/编辑）、各家报价、参与的项目、**采购来源**（"网页资料尚待核实；可另存原始来源及字段证据查看"）、发布到公司资料、删除；**重复建档提示**（相同 / 相似 → 打开已有的 / 合并到这条 / 仍然新建；说明"合并后不能在软件内撤销；其他设备交换数据后也会同样合并"）。

13. **回收站（纠正 v2）**：入口在 设置 › 已删除的记录；内容类型：供应商、物料、项目、报价、预算行、询价单；文案"删除的供应商、物料、项目、报价等会出现在这里，可以随时恢复。恢复后记录回到原处，并随同步与交换传到其他设备。"空态"没有已删除的记录"。**去掉 v2 里的"保留 30 天"和"永久删除"**——Folio 没有这两项。
