## 提示词

你上一轮做的 `Muyon Mobile.dc.html`（沐阳 Muyon 手机端）我们已采纳为视觉与交互基准。请在**不改变已定风格**的前提下补齐缺失部分。先通读已有稿，沿用其 token、组件写法与状态机风格，新稿与旧稿放在同一项目里。

### 0. 产品背景（一段话）
沐阳 Muyon 是以个人 AI 助手为核心的跨端工作空间（Flutter：Android / macOS / Windows），连接个人资料、业务插件（询价、科研、原型）和自己的设备。业务插件保留完整专业页面；助手能用当前项目/选中对象查询、分析并调用已注册工具；写入与外传**逐次确认**；本地优先，无模型时仍能阅读、编辑、检索。所有数字与名称用示意数据，并在页面角落小字标明"示意数据"。

### 1. 已定决定（不要改）
- 底栏/桌面图标轨 5 项，顺序：**AI 助手 · 业务插件 · 工作台 · 数据交换 · 设置**；纯图标、选中实心、无可见文字，但有 aria-label 与 title。
- 名称：沐阳 / Muyon；界面里**不出现 "Folio"**，询价插件就叫"询价"。
- 浅色主色蓝 `#2458D3`；**深色模式里所有蓝色位置改用琥珀**（主按钮、选中、链接、"待确认"）：accent `#F0A649`，选中文字约 `#F5C27A`，选中/待确认底约 `#3A2A12`，按钮前景 `#0A0A0A`。请你核对对比度（正文与按钮 ≥4.5:1）并给出最终值。
- **红色=失败/危险/警告**（含磁盘空间不足）；绿色=成功。琥珀**只**作深色主色，不再表示警告。
- "待确认/待核验"与"可操作/选中"同色系（浅蓝、深琥珀）。
- 记忆放在「助手设置」里；工作台只放「资料」卡片。
- 收件箱 = 批准 · 运行 · 消息；确认卡固定字段：做什么 / 对谁 / 发送内容（可展开）/ 摘要散列 / 后果 / 按钮（外传类为「仅发送这一次」）。
- 业务页（表格、表单）保持 8px 圆角与密度，金额右对齐、保留两位小数；大圆角（24/胶囊）只给壳层与平台页。
- 不用渐变、发光、拟人形象、装饰性指标；状态必须有图标 + 中文，不能只靠颜色。
- 安全语义必须画对：已送达 ≠ 已导入 ≠ 已接纳 ≠ 已读，各自独立显示；本地取消不冒称远端已撤销；模型回答和资料内容不授予权限；逐次确认不可关闭。

### 2. 本轮要补的内容

**A. 桌面端（≥1100 宽，约 1440×900，浅/深）**
布局：`图标轨 72` + `二级栏 240（可收起）` + `内容区` + `右侧助手栏 360（可收起）`。
- 图标轨 = 底栏同 5 项，设置在最下；顶栏：面包屑（工作区 › 插件 › 对象）、⌘K 命令面板入口、收件箱铃铛（角标）、工作区切换。
- 二级栏随一级项变化：AI 助手=对话列表（主要对话/专题对话）；业务插件=插件列表 + 当前插件的功能分区；数据交换=设备/会话列表；工作台=无二级栏；设置=设置分组。
- 画这些屏：① 工作台 ② AI 助手（助手占内容区，此时不再显示右栏）③ 业务插件·询价·报价**表格**（表头 42、行 52、排序、批选、筛选条、右侧详情 MasterDetail ≥1000 并排）④ 业务插件·科研·文库 + 阅读器（右侧助手栏带"针对此论文"范围条）⑤ 数据交换 ⑥ 设置 ⑦ 收件箱（桌面为右侧抽屉或居中面板，二选一并说明）。
- 平板竖屏（约 820×1180）画 1 屏，说明二级栏收起规则。

**B. 科研插件（手机 + 桌面各 1 套）**
功能分区：概览 · 文库 · 任务 · 结果 · 写作。需要：
- 文库列表（论文/研究卡，索引状态徽标：已索引 / OCR 处理中 / 索引失败）；**阅读器**：PDF 页、批注、引用回跳、"精读笔记"；引用块显示原文引句 + 页码 + "无法唯一定位"提示态。
- 任务：创建任务包 → 导出 → 等待回传 → 导回结果包；任务状态（草稿、已导出、执行中、已导回、已接纳）。
- 结果：评估与接纳（接纳/否定+理由+不确定性）；"证据支持程度"与"已接纳"是两个独立标记。
- 写作：提纲 + 关联结果 + 导出报告；研究关系图（点对象可回到实际对象）。

**C. 原型插件外围**
只画外围：原型列表、版本评审、反馈记录、导入入口与权限提示、受限 WebView 的边框/工具栏。**WebView 内部是导入的页面，保持导入原样，用一个灰色占位框并注明"导入内容原样显示"，不要为它设计样式。**

**D. 询价插件其余页面**
项目（预算行、询价单、技术要求）、供应商、物料（含参数表）、回收站。每页给：列表、详情、新建/编辑表单、空/失败态。比价表保留原始金额并可局部横滚。

**E. 记忆管理（在助手设置内）**
列表（来源、作用域、事实/推断标记、过期日期、停用/启用）、编辑、删除（二次确认，写清"删除会传递到后续整理"）、设置过期、Dream 建议的接受/忽略/撤回、经验候选（"验证后才参与任务"）。敏感来源的"请谨慎访问"门保留。

**F. 设备配对与数据包**
配对：发现 → 核对码（或扫二维码）→ 确认；撤销配对（历史保留、禁止发送）。来件"核验"详情页：来源设备指纹、内容清单、大小、校验结果、接纳/拒绝；接纳后"尚未导入业务"的独立状态。数据包导入/导出向导（选择内容 → 目标 → 校验 → 完成/部分失败）。

**G. 模型配置**
添加模型表单：用途（对话与工具 / 向量化）、位置（本机 / 本人设备 / 远程）、名称、端点 URL、模型名、API Key（只写入系统凭据，界面不回显）、验证连接结果。非本机端点需凭据、远程要求 HTTPS 的提示。写明"不会自动切换到其他模型"。

**H. 备份与恢复、数据与存储、接口与 MCP**
- 数据与存储：各模块数据库状态（可用/不可用+原因）、创建备份、校验备份、恢复（二次确认：会先关闭应用、原数据保留在哪）。
- 接口与工具：宿主注册的工具列表（只读/写入/外传标记、搜索、无结果态）、调用记录。
- MCP：服务器列表、添加/编辑/连接/移除；提示"调用会把参数发给该服务器，每次需确认"。

**I. 四项新功能（已决定要做，请把稿补完整）**
1. **数据中心·插件注册与发布门槛**：保留你已有的 本体图 / 动作 / 流程 / AI 知识 四标签，补：① 敏感属性标记与"摘要中已剔除"的可视反馈；② 6 项注册检查失败时的修复指引（每项失败要告诉开发者去哪里改）；③ 示例问法评测的运行中/失败/重跑状态；④ "同步到助手知识库"的进行中、成功、失败、回滚状态。
2. **规则配置**：规则列表排序（优先级拖动）、新建/编辑规则（触发语句 + 参数提取预览 + 绑定接口/动作）、冲突/歧义提示（多条规则同时命中时显示哪条生效）、"试一试"、命中统计、停用/删除。写入类规则的确认不可关闭。
3. **SOUL**：语气、做事原则增删改、字数上限提示、"固定安全规则不可覆盖"区块、改动后"下一次对话生效"的提示；注明"SOUL 与原则文本发往远程模型时会入账到数据去向"。
4. **助手权限**：四个开关（读取 / 写入 / 联网外发 / 调用本人设备）的完整状态：开、关、被关闭后助手提出该类操作时的提示（"该操作类别已关闭，未提出"）、变更审计记录。开关只能收紧，写清"逐次确认不可关闭"。

### 3. 每一屏都要覆盖的状态（给每个页面各出一张或在原型里可切换）
正常 · 载入中（骨架或进度，未知进度不要假百分比）· 空（资料库为空，写清创建/导入入口）· 筛选无结果（带"清除筛选"）· 失败（写原因 + 恢复路径 + 重试）· 不可用/离线（说明原因，其他功能仍可用）。

### 4. 无障碍与适配（请在稿里体现并列出检查结果）
- 宽度：手机 320 / 390 / 430，桌面 1280 / 1440；文字放大 200% 时重排不截断（每类页面至少展示一屏 200% 效果）。
- 触达区 ≥48×48；键盘可达：桌面画出焦点环样式与 Tab 顺序（标注在图上）；⌘K 命令面板。
- "减少动态效果"：说明哪些过渡会被关闭。
- 底栏纯图标：展示长按/悬停 tooltip 的样子。
- 对比度：浅/深各列出主要文字/背景配对与比值。
