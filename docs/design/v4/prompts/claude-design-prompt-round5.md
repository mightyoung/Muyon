## 提示词

第四版（v4）采纳为目标稿。本轮只做**修正与补齐**，不新增本提示词没列的功能。已定决定不变（底栏顺序 AI 助手 · 业务插件 · 工作台 · 数据交换 · 设置；记忆在助手设置；深色主色琥珀；红 = 失败/危险；点击区 ≥48；所有数字标“示意数据”；界面里不出现 “Folio”）。

### A. 警告色（所有文件）
1. 在 `tokens.md` 增加 `warn` / `warnbg` 两个 token：
   - 浅色 `#8A5A00` / `#FFF1D6`
   - 深色 `#E8C547` / `#2E2A10`
   深色值**不得**与 `deep`（`#F5C27A`）/ `tint`（`#3A2A12`）相同。请用工具核对对比度并写入对比度表。
2. 把 `Inquiry Spec+Catalog`、`Exchange Hub`、`Platform Gaps`、`Desktop Spec`、`Desktop Inquiry` 里的私有 `amb` / `ambbg` 改用 `warn` / `warnbg`。
3. `components.md`：“警告条 琥珀”改为“警告条 warn”；报价徽标的 warn / info 色调写明用哪个 token（没有 info token 的，改用 neutral）。
4. 深色模式下分别截一张“选中行”和“警告条”同屏的图，证明两者能区分。规则：警告永远是 `warning` 图标 + 中文。

### B. 助手确认流程：按分级授权重画（`Mobile`、`Desktop`、`Platform Gaps`）
依据 ADR-0002：
- **只读工具不弹确认**。对话页里只读工具画成“已执行”的工具卡（工具名 · 参数摘要 · 结果对象 chip），不要“确认 / 拒绝”。
- **模型请求**按位置区分：本机、本人设备不确认；远程模型在对话里首次发送时弹确认卡，按钮为“仅这一次 / 本次对话允许发往此端点 / 拒绝”。
- **写入**：确认卡按钮为“仅这一次 / 拒绝”，另有“更多”展开“本次任务 / 本次对话 / 始终允许”（同一工具、同一范围；范围可选当前项目或当前工作区）。
- **外传**：发往新端点只有“仅发送这一次 / 拒绝”；发往已授权端点另有“本次对话允许”。外传不画“始终允许”。
- 对话里的确认卡与收件箱使用同一个“确认卡”组件，固定字段：做什么 / 对谁 / 发送内容（可展开）/ 摘要散列 / 后果。
- 被授权自动放行的操作，在对话和执行记录里标“由授权放行 · 查看授权”。
- 状态：待确认、已确认、已拒绝、已由授权放行、授权已过期需重新确认、范围已变化需重新确认、**被内容审查要求确认**（展示原因）、**被内容审查拦截**。审查本期默认不启用，执行记录里显示“未审查”。

### C. 「助手权限」页重画（`Assistant Settings`）
由“四个开关”改为四部分：
1. **模式**：只读 / 标准（默认）/ 自定义，每项一句说明。
2. **授权列表**：每条显示 类别 · 工具或端点 · 范围 · 时长（仅这一次 / 本次任务 / 本次对话 / 限时 / 始终）· 剩余时间或次数 · “撤销”。空态：“还没有授权，助手每次都会先问你”。
3. **变更审计**：授权的创建、使用、撤销，按日期分组。
四类开关保留在模式下方，写明“只能收紧”；关闭后助手提出该类操作时显示“该操作类别已关闭，未提出”。
固定说明区：“模型回答、资料内容、规则和 SOUL 都不能授予权限”“发往新端点每次都会询问”“授权随时可撤销”。删除旧稿里“逐次确认不可关闭”的说法。
4. **外传内容审查**（同页底部一个分组）：已接入的审查器列表（名称 · 来源：插件 / 本机服务 / 远程服务 · 状态）；空态“未接入内容审查，外传内容不经审查，仅凭你的授权放行”；“接入审查器”入口（只画入口与说明，不画配置细节）。
