## 提示词

在 v4 和第五轮修正的基础上，按下面的最新决定补改。已定的约束都不变：
- 底栏：AI 助手 · 业务插件 · 工作台 · 数据交换 · 设置；记忆在助手设置里。
- 颜色：深色主色琥珀；待确认与选中同色系；警告用 `warn`；红色只表示失败、危险和外传。
- 点击区 ≥ 48；所有数字标「示意数据」；界面里不出现 “Folio”。
- 原型插件的 WebView 内部不设计；数据中心里的原型显示「不适用」。
- 只做本提示词列出的改动，不新增功能。

### F. 询价自带的助手收归宿主助手
1. 在沐阳里，询价插件不再有自己的「AI 问答」「AI 任务」「助手历史回答」页面和入口，请删除这些画面。**撤回**第五轮 E 里「询价 AI 任务、助手历史回答的桌面版」这一项。询价概览的桌面版仍然要画。
2. 询价的各个页面加一个「问助手」入口，打开宿主的 AI 助手，并自动带上当前范围，例如「询价单 RFQ-示意」「选中的 3 条报价」。
3. 询价设置里删除「助手权限：自动执行（免确认）」。助手权限统一在「助手设置 › 助手权限」里设置。
4. 询价页面里原有的「复核对话框」，统一换成第五轮 B 定义的确认卡组件。

### G. 范围与外部内容
1. 对话输入框上方显示**范围 chip**：全局 / 工作区 / 项目 / 选中的 N 个对象。点开能看到具体的对象列表。助手的只读操作严格只读范围内的对象；不画「顺着关系读取关联对象」。
2. 不画「把目标加入范围并批准」这类按钮，本阶段不做。
3. **外部内容**：任务里一旦进入了外部内容（联网网页、MCP 或外部插件的结果、导入的供应商文本），就要：
   - 在任务顶部显示 `warn` 提示条：「本任务包含外部内容，已暂停自动放行，写入和外传会逐次询问」；
   - 确认卡增加一个状态「因外部内容需逐次确认」，和第五轮 B 列出的其他状态并列；
   - 在授权列表里，受影响的授权显示「本任务中暂停」。

### H. Agent 内核：代码里已经有、稿里还没画的界面
1. **流式回答**：回答逐字出现；协议文本、工具名和参数不能在正文里闪现。生成过程中可以「停止」。
2. **批量确认卡**：模型一次提出多项操作时，用一张卡列出。每行包括：做什么 / 对谁 / 影响标签（写入、外传）。按钮为「全部允许」「逐项决定」「拒绝」。只读操作不进卡，画成「已执行」的工具卡。
3. **预算**：每个任务有步数、活动时长、token 三项预算，执行中在任务卡上显示进度。用尽时任务停在「已达上限」，给出「再继续一轮」「结束」两个选项。
4. **上下文自动压缩**：长对话里出现一行系统提示「已压缩较早的对话 · 查看要点」。需要确认时弹出确认框，标题「压缩较早的对话以继续」，按钮「压缩并继续」「不压缩」。
5. **执行记录**：
   - 按事件时间线展示：模型请求 → 提出操作 → 确认 → 执行 → 结果；压缩和失败也作为事件出现。
   - 中断的任务显示「从断点继续」，并注明「已完成的写入不会重复执行」。
   - 由授权放行的事件标「由授权放行 · 查看授权」。
6. **模型设置页**：
   - 新增「测试连接」，结果显示是否连通、首字时延，以及是否支持流式、原生工具调用、JSON 模式；失败原因用中文写。
   - 新增「预设」下拉，列出常见服务商和模型，选中后自动填好端点。
   - 新增「流式输出」开关。
   - 密钥输入框永远不回显。

### I. 数据去向、敏感属性与插件能力
1. **数据去向**页：除了模型请求，还要列出工具外传，通道包括 MCP、询价网页取证、公司资料中心、设备传输。
   - 每行：时间 · 通道 · 目的地（只写到域名和路径）· 字节数 · 状态 · 关联任务；
   - 可以按通道筛选；
   - 说明文字：「所有外传都先记账再发送，记不进账就不发送」。
2. **敏感属性**分三类，在实例浏览器和对象详情里默认遮盖，显示「已遮盖 · 个人信息」和「显示」按钮。
   - 个人：电话、邮箱、地址；
   - 商业：单价、成本、毛利、合同额、成交价；
   - 凭据：永远不能显示，不给「显示」按钮。

   点「显示」要先确认，并记一次查看。
3. 插件详情页加「**助手能力**」分组：
   - 「可用操作」：每项带只读、写入或外传标签；
   - 「暂不开放」：每项写明原因，例如「导出类，后续开放」。
4. 插件层级标签分三种：原生插件、声明式插件（MCP / OpenAPI，只读）、内容插件。声明式插件的详情页标注「外部数据：进入任务后暂停自动放行」。
