## 3. 与你已定决定/需求的差异（需要确认）
1. **底栏顺序**：你说「AI 助手、业务插件、数据交换、工作台、设置」，稿是「AI 助手、业务插件、**工作台**、数据交换、设置」（工作台居中）。是有意改动还是误差？
2. **深色主色**：稿的深色 `acc` 是 `#F2F2F2`（白），选中/主按钮是白底黑字；但稿首页文字写"蓝色不变"，自相矛盾。Folio 基线深色是 `#7BA2FF`。请你选：**蓝**（与 Folio/前文一致）还是**白**（更接近 Muse 深色）。
3. **配色**：稿声明"蓝 + 白，红/绿仅用于状态"，并取消了 amber（待确认黄）。而现有代码和 DESIGN.md 用 amber 表示"待确认"。稿里"待确认"改用蓝 tint。若采纳，`muyon_ui` 的 `amber/amberBg` 将不再使用，需决定删除还是保留给警告。
4. **记忆入口**：稿把记忆放在「助手设置」里，工作台没有记忆卡片；你上轮要求"资料、记忆在工作台各放一张卡片"。稿只放了资料卡片。需要补一张记忆卡，或接受记忆只在助手设置里。

## 4. 稿里出现的**新功能**（需求与代码里没有，冻结期不可做，且需产品决定）
| 新内容 | 稿里的含义 | 现状（我核实到的） | 建议 |
|---|---|---|---|
| **数据中心 = 插件注册与发布门槛** | 每个插件必须在这里注册对象、关系（含"查询接口"）、动作（参数/提交条件/副作用）、业务流程、敏感属性、示例问法评测，6 项检查全过才"可以发布"并"同步助手知识库"；不通过的插件显示"不可发布" | Folio 现有数据中心是**询价的本体图 + 数据质量 + AI 接入**（`inquiry_module/.../data_center`）。`muyon_module_api` 的 `ModuleManifest` 只有 id/版本/依赖，**没有**关系、流程、示例问法、"发布"概念 | 这是新平台能力（插件元数据规范 + 评测 + 知识库同步），需要单独的产品/架构决定，**不要混进 UI 任务**。UI 上先只做"本体图（对象/关系/属性）"，其余标签待后端存在再做 |
| **规则配置** | 用户可编辑"预设语句 → 接口 → 动作"规则，带命中次数、"试一试"、启用开关 | 工具选择有规则+LLM 回退（产品总览、`tool_selection.dart`），**没有用户可编辑的规则 UI/存储** | 新功能。要先定义规则存储与优先级，并重申"规则不授予权限" |

| **助手权限开关**（读取/写入/联网/调用设备） | 关闭=助手不能"提出"该类操作；开启仍逐次确认 | 现有设置只有说明文字"只读可执行，写入外传逐次确认" | 新功能；语义与 `ActionGate` 要对齐 |

| **本周发往远程 N 次**、**范围条**、**离线工具模式开关**、**携带近期对话开关** | 助手/账本摘要 | 范围条与近期对话开关已存在于现有助手；本周计数需账本聚合 | 保留（数据都真实可得） |

## 5. 稿未覆盖的需求（要补设计，否则实现会各自发挥）
- **桌面/平板整套**（图标轨 + 二级栏 + 内容区 + 助手栏）。稿只有手机。
- **科研、原型的页面内容**：只有入口卡片（概览、文库、任务、结果、写作；原型列表、版本、反馈）。阅读器/批注、关系图、任务包导出/回导、结果接纳、提纲与报告都没画；原型外围页也没有。
- **记忆管理**：编辑、停用、删除、过期设置、经验候选（稿只有"查看 + Dream 建议"）。
- **设备配对**：核对码/二维码流程、撤销配对、来件"核验"详情（稿只有二维码图标和一行摘要）。
- **模型配置**：添加模型的表单（端点、模型名、密钥、用途=对话/向量）。稿只有位置单选和一段说明。
- **备份/恢复、数据与存储、接口与 MCP**：设置里只有入口，无页面。
- **询价其他页面**：项目/预算/询价单/技术要求/供应商/物料/回收站只有卡片；只画了报价列表和详情。
- **状态矩阵**：载入、空、失败只零星出现（数据去向筛选空态、收件箱空态、发送失败）；大多数页面没有。
- **大字体 200% / 320 宽 / 键盘焦点 / 减少动效**：未体现；底栏图标 28px，无焦点样式。
- **表格**：报价列表在稿里是行卡片；需求要求表格可排序、批选、金额右对齐——手机上的呈现要说明。

## 6. 对我之前的任务拆分的影响
- **UI-0** 不变（现状基线仍需要）。
- **UI-1**（套件）：以此稿为手机端视觉规格。新增/确认组件：`SegmentedPill`（稿的 `seg`）、`TitlePill`（可展开菜单的标题胶囊）、`CircleIconButton`、`ToggleRow`（设置/权限/规则开关）、`GroupedList`（设置分组）、`InboxSheet` 及其 3 标签、`ScopeChip`、`StatusBadge` 的 **蓝/绿/红三态 + 灰**（取消 amber 后）、`SourceRefChips`。token：light `bg #FCFCFC / sf #FFFFFF / sk #F1F3F6`，dark `bg #0A0A0A / sf #141414 / sk #1F1F1F`；**深色主色待你在 §3-2 决定**。
- **UI-2** 手机壳：直接按稿落地；桌面等 Claude Design 出稿。
- **UI-3** 收件箱：稿已给全貌，但"消息"标签内容稿里没画（有 `inMsg` 但无示意）。
- **UI-5** 工作台：按稿；补记忆卡片（§3-4）。
- **UI-6** 数据交换：按稿；补配对流程。
- **新增、暂缓**：N1 数据中心重做（依赖 §4 的产品决定）、N2 规则配置、N3 SOUL/语气、N4 助手权限开关。四项都是新功能，冻结期外、且先要产品说明。
- 稿是 HTML 原型，不能直接搬进 Flutter；实现是用 Flutter 组件**重做**，以稿为视觉与交互规格。
