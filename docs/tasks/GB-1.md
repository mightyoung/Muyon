## 背景
[AI 原生方案](../design/ai-native-ui-redesign-2026-10-09.md) §6 有五条不变量。GROK-8（[追溯表](../reviews/2026-10-10-aiui-acceptance-trace.md)）回答的是「每条要求落在哪」，没有回答「**有没有路径能违反它**」。本任务换攻击者视角找反例。

## 只做这些
产出 `docs/reviews/2026-10-11-invariant-audit.md`，对五条不变量逐条：
1. **不变量 1**：界面上的数值只来自事实绑定或宿主公式。找出所有可能把模型给出的数字渲染成数据的路径（组件属性里的字符串数字、表格单元、图表数据、文本插值等），以及对应的拦截点。
2. **不变量 2**：写入或外传只能经确认卡或授权；成功以回执为准。找出动态界面、本体卡片、批量确认、通用写工具（`apps/muyon/lib/platform/inquiry_record_tools.dart`）里任何「按钮点了就显示成功」或「跳过确认直接执行」的可能。
3. **不变量 3**：外部内容进入任务后不出现放行类按钮。已知 SN-1 刚修了动态确认卡（`surface.dart` 的 `externalContentProbe`，失败即关闭）。查还有哪些确认入口（Folio 询问页、批量确认、授权控制中心、导入审阅、询价清单审阅）的外部内容标记来源可能不可信或缺失。
4. **不变量 4**：校验不过的节点不渲染；流中断不产生半截动作。对照 [流式契约](../design/aiui-stream-contract.md) §4、§6 找反例。
5. **不变量 5**：「只用文字」档下所有功能仍可通过文字和固定页面完成。列出目前只能通过动态界面完成的操作（如果有）。

每条写：**反例或疑点**（`文件:行`、触发条件、后果）、**现有拦截**（`文件:行`）、**结论**（已守住 / 有缺口 / 无法静态确认）、**建议的拒绝路径测试**（一句话，交给后续执行者）。
