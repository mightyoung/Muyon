## 要做
在 `apps/muyon/test/assistant_subconversation_test.dart` 末尾加 2 个测试，复用该文件已有的建库、建子对话、假模型（记录请求体）的写法：

1. `child summary never enters parent model request`
   - 父会话建子对话；子对话里假模型回答一段唯一字符串，例如 `CHILD-SECRET-7f3a`；父侧按现有方式读取子对话（参照第 83 行测试）。
   - 父会话再发一条消息，触发下一次父模型请求。
   - 前提断言：数据库或父侧读取结果里确实存在 `CHILD-SECRET-7f3a`；父模型请求确实发生（请求数 ≥ 1）。
   - 断言：父模型请求体（全部消息与工具结果拼成字符串）不含 `CHILD-SECRET-7f3a`。
2. `parent answer never enters child model request`
   - 父会话里假模型回答唯一字符串 `PARENT-SECRET-91bc`；再建子对话并在子对话发消息。
   - 前提断言：父消息里存在该字符串；子模型请求确实发生。
   - 断言：子模型请求体不含 `PARENT-SECRET-91bc`。
