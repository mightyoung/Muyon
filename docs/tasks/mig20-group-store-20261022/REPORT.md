## Delivered

New `crates/muyon-core/src/group_runtime/store.rs` implements typed local Register/Start/Plan/BindOriginal/Observe/Handoff/Stop commands and opaque current GroupScope. It uses BusinessStore's actual owned connection, current project/workspace/owner identity and existing persisted business_grants. A model/wire Human claim alone is denied; only authenticated compiled host code may issue a domain-bound local grant after current user confirmation/policy, matching the existing trusted issuance boundary. Grant generation/owner epoch/binding/active/expiry are read from disk and rechecked in the effect transaction; committed mutation consumes the grant. These grants are local group-mutation authorization, never AgentOwner execution permission. No account rows, default group, credentials, production policies or external permission are fabricated.

Explicit transactional initialization adds six versioned extension tables without changing strict BusinessStore required schema/meta: group_runtime_schema/groups/runs/nodes/local_intents/events. Register persists real group owner/admin/member/mode/scope/conversation facts only under a real current project. No pre-stored group is assumed. Start captures task leader and member grants. Handoff narrowing is task-local and cannot silently alter another task/group default. Same registered root ID cannot reset its lifetime under a fresh run ID. Plan persists a limited first-level DAG proposal, never a provider queue or execute ticket.

Local pending is durably committed before the effect transaction. Group revision CAS, run epoch/handoff count, task grant narrowing, original-reference/result/dissent state, stop, event, committed local receipt and grant consumption then share one BEGIN IMMEDIATE/COMMIT. A failed SQL tail rolls all of those effects back and leaves original local pending. Reopening or resubmitting the same intent only returns its original local receipt/pending state and does not re-run an effect. Local Committed means recorded coordination facts, not an external task completed. This is a local mutation journal, not a duplicate network/accounting ledger.

Original registration/query requires a real AgentOwner and verifies actual workspace/request conversation against persisted group registration. It performs only request_conversation/request_chain/lookup/ensure_conversation_resolved reads. Source has no prepare/confirm/claim/settle/cancel/configure call on that owner. BindOriginal can register an existing original after stop/deadline/handoff for reconciliation; it cannot create or resend one. Stop persists stopped_unbound for unbound proposals and never assumes that an unregistered request was not already sent. Stop neither cancels a real original nor releases its hold.

OriginalRequestView preserves the bound first request ID, the host's durable chain and actual tail receipt. Prepared/Unknown/tool followups remain gated and identify the real unresolved tail ID. tool_consumed is not reclassified as a terminal success. Handoff always consults the real owner, even without a bound node; it refuses unresolved conversation state and refreshes bound terminal states within the local transaction. Old-epoch original receipts may be reconciled as historical evidence without acquiring new execution rights. Current-epoch claim summaries preserve older observed dissent when an Unknown resolves, alongside source revision/member/node/original reference; source revisions must really exist in research_entries under the same project. Counts are not treated as truth.
