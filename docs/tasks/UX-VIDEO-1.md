## 产品流程与状态

对话里视频具有稳定message/attachment身份、来源、格式/大小/时长（未知时标未知）及可读文件名。展示封面或静态占位、播放/暂停、定位、音量、全屏、下载；默认不自动播放、不自动下载。全屏退出返回原消息、进度与焦点，不生成第二条消息或第二个后台播放器。只用文字/减少动效时保留文件信息与播放/下载入口；播放是用户主动媒体操作，不强制换成循环动画。

区分未加载、待授权、加载中、可播放、缓冲、已暂停、播放结束、取消、失效/被删除、格式不支持、失败。错误给具体可恢复说明；不支持时仍可在允许的范围内下载或由用户打开已验证本地文件，不自动启动外部应用。切会话/离页/销毁释放解码器和焦点、停止声音；再次进入是否恢复位置由评审确定，至少不能自动恢复播放。

## 来源与权限矩阵（设计建议，须逐项评审）

| 来源 | 播放/下载路径 | 权限、失败与模型边界 |
|---|---|---|
| 本地受管附件/已收到文件 | 宿主解析受管ArtifactRef；用户点击播放；下载＝用户选择目标位置的本地副本 | 验证会话归属/文件可用性，不接受模型任意路径；沙盒或系统文件选择器，取消零写入；无联网/模型消费 |
| 用户通过系统选择器添加的本地视频 | 已获选择范围的文件引用/受管拷贝；进度/失败明确 | 不扩大目录授权，不扫描同目录；来源保持user-selected，不把视频上传给模型 |
| 受控远端附件（宿主已登记端点/对象） | 用户点击后检查权限，获准才流式或临时受管缓存；下载单独保存 | 请求/Range/重定向均约束获准端点及范围，账本入账；凭据仅现有安全存储，不写消息/日志/URL；过期链接重新取受控引用，禁止任意URLfallback |
| 模型文字或外部内容中的URL | 首版只展示文本/来源链接，不自动升级视频、预取封面或加载 | 模型不能提供受信attachment、headers、路径或grant；若以后支持URL视频，另提交来源/SSRF/重定向/权限决策，不默认允许 |

远端播放的请求可能泄露网络身份和资源选择，不等于本地查看；依现有 [ADR-0002](../adr/0002-graded-assistant-authorization.md)、[ADR-0004](../adr/0004-module-contract-v2.md)与出站策略核对端点/授权，授权被撤销后关闭新请求和后续分段。进入任务的外部内容仍触发既有收紧，不给放行类按钮。普通问答不增加确认；本地用户选定文件的播放不弹业务确认。下载由明确用户点击与目标选择发起，本机拷贝沿现行宿主授权分类；若需新增授权例外必须ADR提案，不自行改policy。向别的设备发送视频是外传工具，独立审批/账本/回执，不以下载动作代替。

文件名清理路径分隔/控制字符，验证输出目录与受管文件归属；目标已存在时使用系统覆盖选择/安全新名称，不静默覆盖。远端实际内容类型、体积和媒体格式核验后才解码；设置可审的缓存/大小/时长/并发预算，超限停止并提供明确退路，不接受可执行文件或可执行HTML充当视频。具体阈值与缓存清理周期待平台owner评审，不编造当前已有限制。

## 取消、去重与恢复

- messageId＋attachmentId＋sourceVersion作为资源身份；播放准备/下载各有requestId/epoch。同资源在途重复播放或下载只加入现有操作，不并行写重复文件；下载成功再次点击可以由用户另存，不能永久吞掉合法操作。
- 下载取消关闭请求/文件句柄，删除该请求的临时文件，不动原视频和其他下载；不显示成功回执。取消后晚Future/晚字节不得覆盖新状态、生成完成通知或重启播放器。网络已发部分请求不能宣称撤回远端副作用。
- 取消/失败/应用退出留下的临时文件可由受管缓存清理；断点续传须来源version/长度/校验一致，否则重新开始，不能续接另一个视频。仅在有实际IO确认后记录保存位置/成功，模型文字“下载完成”无效。
- 同一播放会话的内嵌/全屏共享播放状态；多个消息的声音仲裁规则需评审，首版建议只允许一个主动播放器。切源/撤权/文件移除后旧控制器立即失效。

## 平台、模型消费和组件边界

移动端Android、桌面macOS/Windows分别验证横竖屏、安全区、返回键/全屏退出、音频焦点、后台暂停、DPI/鼠标键盘。Web预览需验证浏览器gesture/全屏/Blob下载/CORS并提供能力缺失退路；Web样例通过不算原生三端通过。iOS沿既有后阶段计划，不因本任务提前承诺已支持。字幕轨存在时支持开关；无字幕明确未知，不自动生成转写；所有控件有文字/读屏语义，键盘与200%字号可用。

**播放器消费媒体字节不等于模型获得视频。** 首版模型只可引用宿主允许的附件ID与最小元数据，不把帧、音频、缩略图、完整路径/签名URL/认证header送模型。用户另行要求理解视频时，必须声明模型能力、采样/转写预算、来源权限、所选端点及外发内容；本地/本人设备/远端模型分别走现行model gate。无视频能力时说明不可用，不偷偷抽帧或换云端。模型不能生成可信视频资源或执行播放/下载IO，只能建议宿主已登记资源。

优先复用FileCard/现有对话附件呈现；本任务不把Video组件/op静默加入stream/1。若需要正式Video组件或媒体引用类型，向F5b目录/契约owner交单独版本化提案：component schema、受管sourceRef、拒绝矩阵、恢复codec、文字退路与模型消费边界，评审通过再实施。stream编排复用现有validator/renderer与宿主动作路由，不另造执行器或让模型下发任意URL/代码。用户要的Intelligent UI现有组件范围继续保持，不裁剪33组件交付来换媒体捷径。

## 任务交付与验收

交付：流程/状态稿、上述来源权限矩阵的审定版、播放器/存储候选与现有依赖审计、平台能力矩阵、取消去重协议、模型边界、必要公共接口/依赖的ADR提案，以及允许文件和验收清单。媒体/文件owner持有新的资源解析/下载与缓存文件；对话owner持有assistant消息/附件展示；F5b独占catalog/surface/core，AUTH owner独占gate。`screens/chat`是设备聊天现有入口，不因名字相同就默认迁入助手视频；实现前核对两种会话的数据归属，避免另造对话数据库。

| 验收场景 | 必须实际断言 |
|---|---|
| 本地播放→全屏→退出→下载 | 同attachment、进度/焦点保持、无双音轨；下载目标正确，源不变，成功只认真实保存 |
| 远端获准/拒绝/撤权/过期/跨端点重定向 | 请求计数与账本正确；拒绝/撤权后无新请求，凭据不出现在消息/日志 |
| 双击播放/下载、取消后晚返回、切会话销毁 | 同版本无重复IO、无晚成功/重启，临时文件回收，不误删别的任务 |
| 恶意文件名/任意路径/非媒体/超限/失效版本 | 拒绝或可读退路；不越目录、不执行、不静默覆盖 |
| 普通问答、模型无视频能力、未请求理解视频 | 问答0新增确认；模型字节/帧/音频发送计数0；无隐式远端fallback |
| Android/macOS/Windows＋Web | 真正加载/控制/全屏退出/下载、后台/键盘/读屏/200%；未测端标未测 |
