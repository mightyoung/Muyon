## Budget and final owner

Count the FULL serialized wire body including historical roles/content/framing, current input and max output under the existing synthetic byte-bound rule and per-call8192/1 reservation. If history does not fit, chat_context_budget_exceeded without reservation/exchange; do not retry with history dropped. Source classification/lineage remains distinct from budget approval. The compile-time provider reviews every message and role, not only message0; fake usage reports actual serialized byte count and response byte count, not real tokenizer/currency. The durable owner still pins the same full context and body and rechecks authority/capability under its final handoff guard. Production remains unconfigured/default-deny.

Final owner guard explicitly checks every history unit against current State.chat (workspace/conversation/owner/mode/revisions/sensitivity/input+output rules and both actual text scans), exact role/content correspondence for the complete wire, unique ordered ancestors and the original admission/attempt rows. Each unit's historical request/body/context/task/input_ref and ancestry must match that same owner's durable reservations/chat_contexts/chat_attempts. No new table or foreign callback is required. Historical answer authorship/content is revalidated from the trusted Rust completed receipt immediately before exchange; the sole Rust worker/root lease prevents any supported concurrent mutation of those completed records. The owner guard prevents concurrent authority replacement and is held through fake handoff; it is not claimed as a cross-store transaction or defense against hostile same-UID edits outside the root lease protocol.
