## 规则（D3，用户已定）
- `research.delete_section` 实际会删除的 outline 行（`outline WHERE section_id=?`，**不得加 project 过滤**）中，任一行的证据属于本次写范围之外的项目 → **整次拒绝**，零删除，错误里不泄露 foreign ID / 名称；
- 关联属本项目但证据不可读、已不存在或类型无法可靠判断 → 允许删除该关联，证据实体不动；
- 超出完整预览预算（默认 500 条关联、1 MiB）→ 整次拒绝；
- section 本身不在范围 / workspace 解绑 / 模块撤销 → 整次拒绝（现有行为保持）。
