1. 新增受信 `HostEffectIntent.localExport`，由宿主适配器构造（无 JSON 解码入口），绑定：工具与调用身份、阶段（`stage` = 生成 A / 保存 B）、解析后范围摘要、准备版本、宿主文件名与格式、内容 SHA-256、目标能力身份（B 阶段）、创建或覆盖方式、策略版本。

4. 目标能力类型宿主私有构造；知道其 ID 或伪造同形字符串都不能通过审批校验。
