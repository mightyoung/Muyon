## 对照协议

锁定任务集/fixture hash、模型版本、采样设置、工具、预算、压缩触发规则及来源权限。比较现有摘要、等预算加长摘要、摘要加检索、摘要加三对象；可容纳时增加全文对照。相同输入预算并不保证相同总成本，分别报告。
多次压缩、失败恢复、决定变更任务必须纳入；预先固定重复运行和统计方法，样本小则保留不确定性。
报告任务通过率、无效重复调用、过时决定复用、unknown误成功、证据可核验率、总token、压缩耗时、恢复耗时和端到端延迟；神经扩展还计编码成本、GPU秒和显存。
越权、重复副作用、遗忘复活或新决定丢失任一出现即停止推广。若不能稳定胜过简单检索/摘要，不加默认复杂度。
新增模型调用、下载、GPU或付费不由本文自动批准。
