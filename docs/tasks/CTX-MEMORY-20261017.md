## 14项新增验收（全部未运行）

| ID | 场景 | 必须满足 |
|---|---|---|
| CTX-T01 | 同条件失败多次后压缩 | 来源与条件保留，不能反复盲试；不把候选解释当事实 |
| CTX-T02 | 工具版本/参数/环境改变 | 可重新评估，不形成永久禁重试 |
| CTX-T03 | 用户部分替代决定；模型伪造替代 | 正确范围生效，伪造被拒，其他旧约束保留 |
| CTX-T04 | 超时后效果不明 | unknown 保留，摘要不能变成功/确定失败 |
| CTX-T05 | 压缩期间取消/撤权，随后迟到回执 | 无新副作用，真实回执仍入原账本 |
| CTX-T06 | 调用配对和未发送输入跨边界 | ID关联完整，未发输入不丢不重复发送 |
| CTX-T07 | CAS期间插入新turn | 旧候选不可发布；重建有界 |
| CTX-T08 | 提交前后崩溃/重启 | 完整旧或新版可见，无半提交与重复执行 |
| CTX-T09 | 来源遗忘/策略关闭/备份恢复 | 派生视图失效，墓碑优先，不复活 |
| CTX-T10 | 来源被改写/丢失/跨scope | revision冲突或不可读明确，不泄露或假核验 |
| CTX-T11 | 摘要失败/预算不足 | 只回退仍有效上下文，否则暂停；不丢必要状态 |
| CTX-T12 | 插件缺少扩展/恶意声明降敏 | 缺省兼容，宿主拒降敏/越权；加入合成第三域 |
| CTX-T13 | 多次压缩与模型切换 | 稳定引用可核查；不复用不兼容软向量 |
| CTX-T14 | 两端展示所有上述状态 | unknown不隐藏，成功有回执，节省数不伪造 |

## 对照协议与判定分离

以[完整协议](../design/remory-isolated-validation-20261018.md)的 V0–V5、T/P 因子对照及 N0–N3 为准；所有样本数和阈值待冻结。软件合同通过、模型任务有效、资源与运维、生产实施授权分别填写，不互相抵消。
锁定任务集/fixture hash、模型版本、采样设置、工具、预算、压缩触发规则及来源权限。比较现有摘要、等预算加长摘要、摘要加检索、摘要加三对象；可容纳时增加全文对照。相同输入预算并不保证相同总成本，分别报告。
多次压缩、失败恢复、决定变更任务必须纳入；预先固定重复运行和统计方法，样本小则保留不确定性。
报告任务通过率、无效重复调用、过时决定复用、unknown误成功、证据可核验率、总token、压缩耗时、恢复耗时和端到端延迟；神经扩展还计编码成本、GPU秒和显存。
越权、重复副作用、遗忘复活或新决定丢失任一出现即停止推广。若不能稳定胜过简单检索/摘要，不加默认复杂度。
新增模型调用、下载、GPU或付费不由本文自动批准。
