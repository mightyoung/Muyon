# OC-11 会话事实为 unknown 或损坏时，已有 clean 任务必须降为需要确认（CR-10 F4）

分支 `task/oc-11-session-fact-unknown` · 基线 develop · 执行：opencode · 审查：leader A（授权安全路径，会复核与变异）

## 问题
`apps/muyon/lib/platform/grants/host_authorization_facts.dart` 的 `readTask`（约 213～260 行）：任务自身事实为 `clean` 时，只有会话事实 `history?['taintState'] == 'tainted'` 才会提升为 tainted。如果会话事实行**存在**但 `taintState` 是 `unknown`，或者内容损坏（`_read` 返回 `null`），结果仍是任务自身的 `clean`，不要求确认。应改为：这两种情况下返回 `unknown`。会话事实行**不存在**时保持现状。

## 只改 `readTask` 这一处
1. 在 `readTask` 里取到 `history` 之后，判断会话事实行是否存在：
```dart
final historyKey = 'auth1b:conversation:$conversation';
final historyRowExists = database.raw
    .select('SELECT 1 FROM settings WHERE key=?', [historyKey])
    .isNotEmpty;
```
   （原来读取 `history` 的那行改成用 `historyKey`，行为不变。）
2. 把计算 `taintState` 的表达式改成：先按原逻辑判断 tainted（`_deny` 两项或 `history?['taintState'] == 'tainted'`）；否则，若 `(historyRowExists && history == null) || history?['taintState'] == 'unknown'`，返回 `HostTaintState.unknown`；否则保持原来的 `HostTaintState.values.byName(value['taintState'] as String)`。
   注意：任务自身已是 `tainted` 时必须仍是 `tainted`（tainted 优先于 unknown）。
3. 不改 `_read`、不改其他方法、不改 `requiresConfirmation`。
