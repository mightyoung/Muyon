## 背景
[ADR-0004](../adr/0004-module-contract-v2.md) §4.3 给本体里的每个字段加敏感度标记：`none` / `personal` / `commercial` / `credential`。合规套件要求每个字段都审阅过，不能是 `unreviewed`。按 §12.1 Q7，初稿的方向是：联系人电话、邮箱、地址归 `personal`；单价、成本、毛利、合同额、成交价归 `commercial`；其余为 `none`。**最终划分由用户确认。**

## 只做这些
产出 `docs/reviews/2026-10-07-inquiry-sensitivity-draft.md`：
1. 按 `packages/supplier_core/lib/src/ontology.dart` 里的每个对象类型，逐个列出字段，每行包括：字段名、中文标签、类型、建议敏感度、一句理由、`文件:行`。
2. 单独列出「拿不准」的字段，例如备注、附件路径、供应商名称、税号、银行账户、公司资料中心的令牌字段，并写明两种归类各自的后果：
   - 遮盖它，会影响助手和数据中心的哪些功能；
   - 不遮盖它，有什么风险。
3. 列出字段之外可能带出敏感信息的地方（例如导出文件、`describe` 输出、`ontologyCard()` 文本），只记录，不判定。
4. 文档开头给一张汇总表：各类别的字段数，以及需要用户拍板的字段清单。措辞要让非开发者看懂。
