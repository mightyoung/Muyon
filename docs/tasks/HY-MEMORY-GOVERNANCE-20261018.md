## 故障与恢复验收矩阵

测试必须真正落 SQLite 文件并重新打开；至少关键场景以独立子进程退出/重开，不能靠内存 mock 声称持久可靠。测试中断点应显式且仅用于合成 fixture。先记录预期失败（RED）再实现。

| ID | 故障/负例 | 必须观察的结果 |
| --- | --- | --- |
| T01 | 墓碑写后、outbox 写前事务中断 | 未提交事务全部消失；不返回成功；重开无半提交 |
| T02 | commit 成功后进程退出、worker 尚未运行 | 重开墓碑仍封锁，outbox 可发现并重放 |
| T03 | 同 key 同 payload；同 key 异 payload | 前者同一回执/一次语义，后者冲突；不错误复用成功 |
| T04 | expected_revision 旧、authority 旧或 policy 收窄 | 原子拒绝；无半墓碑或半队列；不能靠入队快照通过 |
| T05 | sink 清理后、确认前退出 | 重开幂等再清理，不复活；确认后仅一次完成语义 |
| T06 | 多 sink 一个失败或未知，另一个 done | 保留各项结果；全局不显示已清理；失败可重试，未知须核对 |
| T07 | claim 后退出/过期、重试再次失败 | durable attempt/重试信息可恢复；不丢任务、不恢复读权 |
| T08 | 候选构建后撤权/墓碑先提交 | 最终 consume 拒绝旧投影；不是只测先撤权后读取 |
| T09 | consume 先线性化，再撤权 | 如实记录已经消费，后续读用封锁；不承诺撤回 |
| T10 | 组合一成员 content/source 变更或权限失效 | 整体旧组合不可消费；有效成员重建需新核验 |
| T11 | authority/存储不可用、presence UNKNOWN | 显式未知/错误；不得返回空或缓存 ABSENT |
| T12 | UTF-8 中文、emoji、越界、字符中部 byte offset | 合法范围精确定位；非法范围拒绝 |
| T13 | 原文 A + redacted B + 原文 C | A/C 可分段定位；ABC 不能冒充连续原文；替换段非原文 |
| T14 | span 来源更版/撤权/墓碑/digest 不符 | 引用失效或未知，不透过定位读取撤销正文 |
| T15 | 恢复旧生产备份、域外凭据丢失 | 本批未实现；明确不作实验通过声明，沿用 D06 门禁 |
