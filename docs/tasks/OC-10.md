## 背景
`apps/muyon/lib/assistant/agent_dispatch.dart` 约 823～826 行：
```dart
bool _correctableRead(Map call, ToolCallResult result) =>
    call['access'] == ToolAccessLevel.read.name &&
    call['effect'] == ToolEffect.read.name &&
    result.status == ToolCallStatus.invalidArguments;
```
只有**只读**工具返回 `invalidArguments` 时，结果才会交回模型让它改参数重试；**写**工具返回 `invalidArguments` 时，任务必须失败、不能继续下一轮模型请求。Haiku 在 HK-4 指出这条（GB-4 缺口 G5）还没有测试，并建议用下面的写法测。
