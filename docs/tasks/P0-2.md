## 背景
工具选择只有离线规则基线（精确 id 匹配，54/140）和已暂停的 Laya 实验；`docs/implementation/tool-selection-eval-2026-10-05.md` 中 LLM 一行是 not measured。需要在同一 140 题上测出 LLM 原生 function calling 的基线。

草稿在 `3d603fa`：`selection_eval.dart` 新增共享评分 `scoreChoices`（离线规则数字不得改变）；`llm_selection_eval.dart` 有 `functionTools`（id 中 `.` 编码为 `__`）、`chooseWithModel`（`tools` + `tool_choice: auto`，无调用即 none，错误返回不抛出）、`LlmChoice.decision`（错误与未注册名是错误选择，不得算作正确 none）、`scoreLlm`、`llmSelectionReport`。草稿未编译过，执行者接手并负责其正确性。

## 交付
1. 草稿编译通过、`flutter analyze`（apps/muyon）无问题、行为正确；覆盖 content 为 null、缺 tool_calls、缺 function.name、缺 usage、非 200、坏 JSON、解码为未知 id 等边界。
2. `apps/muyon/test/llm_selection_eval_test.dart`：回环 `HttpServer` 夹具模型。覆盖请求体（系统提示、`tool_choice: auto`、全部工具编码名与效应说明）、命中、无调用为 none、HTTP 500 与未注册名计错且不算正确 none、写入工具误选计数、用量累计与"usage not reported"、报告含逐题表；并用 140 题夹具全量跑 `scoreLlm`，对精确 id 题回显期望工具、其余不调用时应复现离线规则的分类 top-1。
3. 同文件中由环境变量门控的真实运行：设置 `MUYON_EVAL_MODEL_ENDPOINT` 与 `MUYON_EVAL_MODEL_ID` 才运行，`MUYON_EVAL_MODEL_KEY` 可选（环境变量 SecretStore）。回环地址为 local，其他为 remote（需 HTTPS）。仅当另设 `MUYON_WRITE_EVAL_REPORT=1` 时写新文件 `docs/implementation/tool-selection-llm-baseline.md`；不得改写 `tool-selection-eval-2026-10-05.md`；普通 `flutter test` 不发真实请求。
4. `llm_selection_eval.dart` 顶部文档注释给出完整运行命令。
