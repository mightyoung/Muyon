## 交付
1. **`selection_eval.dart`**：共享评分函数 `scoreChoices`。离线规则的数字不得因重构改变，已有的 `selection_eval_test.dart` 必须不改动就能通过。
2. **`llm_selection_eval.dart`**：
   - 工具 id 中的 `.` 编码为 `__`；
   - 请求带 `tools` 与 `tool_choice: auto`，模型没有调用工具即视为 none；
   - 请求失败、返回未注册的工具名，都算错误选择，**不得**算作正确的 none；
   - 覆盖以下边界：content 为 null、缺 `tool_calls`、缺 `function.name`、缺 `usage`、非 200、坏 JSON、解码后是未知 id。
3. **`apps/muyon/test/llm_selection_eval_test.dart`**：用回环 `HttpServer` 做夹具模型，覆盖以下情况：
   - 请求体：系统提示、`tool_choice: auto`、全部工具的编码名与效应说明；
   - 命中；没有调用为 none；
   - HTTP 500 与未注册名计为错误，且不算正确的 none；
   - 写入工具误选的计数；
   - 用量累计，以及「usage not reported」；
   - 报告包含逐题表；
   - 用 140 题全量跑一遍 `scoreLlm`：夹具对精确 id 题回显期望工具、其余题不调用，结果应复现离线规则的分类 top-1。
4. **真实运行**：写在同一个测试文件里，用环境变量控制。
   - 只有设置了 `MUYON_EVAL_MODEL_ENDPOINT` 与 `MUYON_EVAL_MODEL_ID` 才运行；`MUYON_EVAL_MODEL_KEY` 可选，通过环境变量 SecretStore 读取；
   - 回环地址视为 local，其他视为 remote，remote 必须用 HTTPS；
   - 只有另外设置 `MUYON_WRITE_EVAL_REPORT=1` 时，才写新文件 `docs/implementation/tool-selection-llm-baseline-<slug>.md`；
   - slug 的规则：modelId 转小写，连续的非 `[a-z0-9]` 字符替换为一个 `-`，去掉首尾的 `-`，例如 `qwen3:8b` → `qwen3-8b`；slug 要有单元测试；
   - 不得改写 `tool-selection-eval-2026-10-05.md`；
   - 普通的 `flutter test` 不发任何真实请求。
5. 在 `llm_selection_eval.dart` 顶部的文档注释里写出完整的运行命令。
