# P0-3 询价 North Star 纵向链路

分支 `worktree-agent-aeed2e9750de4aa36` · 执行 senior（Opus）· 审查 engineer（Sonnet）

## 目标
验收账本几乎没有真机（R）与真实模型（M）证据。做一条端到端链路自动测试：本机无头时用回环夹具模型运行；设置环境变量即可在真机、真实模型上运行并产出证据。

## 链路
`MuyonHost.open(新数据目录)` → 激活询价模块 → 用模块自己的领域函数建项目、预算行、两家供应商报价（参照 `inquiry_write_tools_test.dart`、`business_tools_test.dart` 的做法，不另造数据通路）→ 个人助手经注册工具回答只读问题（比较报价、项目预算）→ 助手提出写入（如经 `inquiry_write_tools.dart` 创建询价单）→ 用预览摘要调用 `PersonalAgent.confirm` 审批 → 写入在询价库可查、结果引用该对象 → `host.close()` 后重开同一目录 → 对话、任务记录、工具回执、`outbound_requests` 仍在且一致。每轮模型调用目前都需确认（stage `model`），测试按界面方式读取 `requestDigest` 确认。

## 交付
1. 共享链路驱动（`apps/muyon/integration_test/support/` 或类似位置），被以下两处使用：
   - `apps/muyon/test/north_star_inquiry_test.dart`：无头、回环夹具模型，按助手协议返回 JSON，随普通 `flutter test` 运行。
   - `apps/muyon/integration_test/north_star_inquiry_test.dart`：同一链路，`IntegrationTestWidgetsFlutterBinding`，可在设备上运行。
   - 设置 `MUYON_EVAL_MODEL_ENDPOINT` + `MUYON_EVAL_MODEL_ID`（可选 `MUYON_EVAL_MODEL_KEY`）时使用真实模型；设备上环境变量不可达，同时支持 `--dart-define`。真实模型下只断言不变量（工具只来自注册表、写入只在审批后、记录重开后仍在、账本有行），不断言措辞。
2. 设置 `MUYON_EVIDENCE_OUT` 时写 JSON 证据：模型端点/id 或 "fixture"、设备/平台、各步耗时、任务状态、账本计数。夹具运行明确标注"不是真实模型证据"。
3. 新文件 `docs/implementation/north-star-inquiry-runbook.md`：无头夹具、桌面真实模型、Android/macOS 设备真实模型三种运行命令；证据如何回填账本、支持哪些行（2.3、7、9a）；如实说明夹具运行证明了什么。
