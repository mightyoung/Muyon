Pre-integration gate: record exact version/artifact SHA/license/SBOM/font hashes; security and dependency review; approved execution location; no network/macros/external refresh or credentials; read-only source and isolated copy; CPU/memory/expanded-byte/page/time caps; cancellation/failure/unknown states and audit logs. Any new paid SDK/cloud transfer/credential requirement needs its own explicit authorization. Do not silently fall back to cloud conversion.

For every candidate/operation: use original synthetic complex corpus (Chinese/Latin fonts, sections/headers/fields/revisions/comments; themes/masters/charts/animations; named ranges/hidden sheets/precision/1900+1904 dates/dynamic formulas/caches/external references; PDF CropBox/rotation/forms/annotations/encryption/signatures). Declare one intended change and byte/semantic invariants first. Save source/output hashes and member manifests; reopen output with independent parser; compare text/data/comments and opaque parts; render before/after at pinned fonts/DPI and review differences; report formula text/display/cache/recalc separately. An unchanged ZIP is no proof of visual or formula correctness.

Acceptance dimensions use pass/fail/unknown/not_run independently. Fail missing unknown parts, unintended semantic changes, stale recalculation claims, visual regressions, scope leaks and any rewritten source. Unsupported high-risk features reject or quarantine; never infer full editing from a container check. Include negative cases, crash/timeout/cancel injection and immutable-original verification. No adapter can be labeled usable until evidence, licensing and independent review all pass. Leader B retains sole develop integration authority.
