## Concrete providers now supplied

`linux/kernel.py NativeLinuxSystem` implements real Linux procfs/cgroupfs/fstatfs/pidfd/Popen/select/pipe/snapshot/reap calls. `linux/backend.py LinuxBackend` implements every HostOSBackend abstract method, not an interface stub. `linux/session.py LinuxHostSession` verifies registered broker observation objects against pinned artifacts and exact scope records. `linux/provider.py provision` wires these into original Authority/TrustedRuntimeBinding only through trusted application objects; absent config/scope table or insufficient native qualification returns HOLD before process creation.

`host_stage.py` and `bootstrap.py` contain actual launch/pause/release/worker invocation source. `worker_permit.py` consumes one child-local opaque permit from inherited authenticated FD, never a serialized Capability. Three existing library workers notify engine entry after the library import and before document editing. That event means **entered the engine edit entry**, not successful edit/reopen/render/recalc/save/commit. Independent snapshot/oracle and host terminal evidence remain mandatory. Current old worker CLI/bootstrap-less main still HOLD.

## Predelegated resources and ownership

This implementation requires a dedicated, single-thread, already-NNP/unprivileged/subreaper Linux x86_64 broker with no other children. It does not set host subreaper/NNP flags, create/configure cgroups, change controllers or resource limits. It opens a host-predelegated exclusive empty cgroup2 directory with pinned device/inode, owner and0700 mode, and observes existing memory.max/pids.max/cpu.max/swap/oom-group limits. It requires an empty private host-provisioned tmpfs workspace no larger than32MiB, plus an already read-only reviewed runtime image. Missing resources or APIs HOLD. Only attaching the already-owned job process (`cgroup.procs`) and terminating its predelegated domain (`cgroup.kill`) are source operations, never provisioning.

reserve records its Attempt **before launching** a pinned trusted host-stage. Host-stage cannot exec bwrap before kernel-credential hello is registered, pidfd/starttime are held and that process is observed in its existing resource domain. It then receives isolate over private inherited FD and execs the exact hash-verified bwrap descriptor. Its children inherit the owned domain. The paused sandbox bootstrap has its own inherited FD and host-visible SCM_CREDENTIALS PID; ready reads actual kernel state while it waits. Logical spawn merely consumes the original Authority grant under its same RLock and releases this registered bootstrap, not a second process.

Controller now reconciles ownership whenever reserve touched OS but no logical-spawn handle exists, including ready refusal/cancel before spawn. The backend returns the reserve-owned process for TERM/KILL/reap. Uncertain Popen setup attempts a bounded credential/PIDFD recovery; unresolved identity/reap stays outcome_unknown and quarantines rather than retrying/deleting a live workspace. Known root PID signals use the original pidfd; descendant pidfds are opened and membership/starttime rechecked. cgroup.kill targets only the pinned exclusive domain. Root poll success alone is insufficient: resource domain must be empty and the dedicated preconfigured subreaper must have no unreaped owned children before snapshot/cleanup.

## IPC and snapshot boundary

Stream framing is version1: v/kind/attempt/request/seq/payload, length capped16KiB, complexity/string/integer budgets, strict keys/duplicate/nonfinite checks, at most16 sequenced messages each direction. Actual send/recv loops handle partial I/O, bounded monotonic timeout, EOF, unsolicited FD rights (closed/rejected), peer PID/UID changes and replay. Any protocol failure poisons/closes the channel; no resynchronization/retry. Host authenticates actual SCM_CREDENTIALS sender against the registered process. Inside a private PID namespace the already-inherited parent peer translates to pid0; this is allowed only in fixed FD3 child bootstrap using kernel peer credentials, never an ordinary request field. It conveys no production authority outside the registered broker attempt.

Source/job/launch are read-only, launch is sealed memfd, output is separate private dirfd. Child-local source/operation/hash/path/expiry/engine checks precede lazy third-party import. The original parent's Capability is consumed locally inside Authority.dispatch_worker's lock, never serialized. Native broker creates opaque ready/terminal proof objects only from its registered native implementation; fake syscalls cannot qualify LinuxHostSession. Old simulation/fake receipt JSON cannot create native proof or host validator authority. Trusted arbitrary Python inside the application is outside the JSON/data threat boundary.

Logs are read and counted from actual pipes through EOF **before** reporting process exit; root exit0 never discards remaining stdout/stderr or entry IPC. Size excess fails, stops and reaps. Native snapshot opens only fixed basenames through pinned dirfds O_NOFOLLOW/O_NONBLOCK, checks regular/single-link/bounded size and before/after inode/device/size/timestamps and exact file set; it is unavailable until whole-tree reap. Original immutable bytes and job hashes plus existing strict OOXML oracle remain mandatory; no unknown part or normalization exception is added.
