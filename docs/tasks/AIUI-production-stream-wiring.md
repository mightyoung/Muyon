# AIUI 生产流式接线：第一源码切片

依据 ADR 与 `AIUI-DEFAULT-ENABLE-PLAN.md` 的固定版本
`6c821d6e4ea642cf60cad64cbe90083d48964231`，本片先接生产编译链和安全边界。

## 本片范围

- 真实网关 TextDelta 进入宿主冻结的 stream/2 session，使用 library-2 目录。
  按行编译原始候选；坏行、未 end、超限、end 后内容和传输失败均拒绝。
  预览只有无动作状态文本；原完整候选通过终态及批量校验后才创建正式组件与事件路由。
- inquiry 真实当前选择的已保存记录提供完整 pin 与敏感值遮盖后的宿主事实。
  事实注明来源对象和修订；不冒称模型或工具回执，不新增业务计算或写工具。
- 单一宿主三档设置实例持久化并恢复：自动、少用、只用文字。
  当前缺省仍为只用文字；旧布尔值和损坏值保守降级，不自动开启。
  少用仅由用户明确的“规划此回答”控件创建、同步冻结本请求身份；模型不能设置身份。
  成功保存使旧策略与旧身份失效，持久失败保留旧值，关闭先拒新保存再排空。
- 动态确认与批量确认使用宿主权威外部内容标记；未知按外部处理。
  路由在创建业务子任务前拒绝未知或改变的来源，子任务继承原授权事实。
  不因展示档位隐藏既有确认与拒绝，不扩大授权或消费持久 grant。
- 正式 inline 组件收到会话、inquiry 或模块变化时立即撤下旧能力，再重新校验来源。

## 必须继续完成的后续范围
