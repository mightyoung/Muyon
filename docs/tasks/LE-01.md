## 范围（只改 `packages/muyon_module_api`；不改宿主、不改科研模块、不开放任何工具）
1. `DestinationRule.localExport`：只表达「使用宿主本机导出门面」，不含路径、允许根或目录。
2. 模块可选能力 `local_exports`（沿 ADR-0004 §4.5 可选能力方式）；声明本身不授予任何保存权限。
3. 不可变、深冻结的准备 / 结果类型：导出准备的通用部分（导出种类、格式版本、MIME、生成时间、冻结字节、字节数、SHA-256、来源对象清单与修订、去重对象计数、排除项与原因、警示、准备版本、清单摘要）；分阶段结果（生成、保存各自 succeeded / cancelled / failed / interrupted / unknown，以及清理结果）。
4. 网络 `DestinationRule`（fixedHosts / publicWeb）与 `NetworkPolicy` 行为保持兼容。

## 测试先行
缺 `local_exports` 能力却声明 `localExport` 目标 → 拒绝；`localExport` 与网络规则混用 → 拒绝；非 `ToolEffect.export` 效应用 `localExport` → 拒绝；类型深不可变（调用方事后改 map / list / 字节不影响）；v1 与不声明新能力的 v2 模块行为不变；现有网络目标测试全通过。
