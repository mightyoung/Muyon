# K-2 模型适配层、流式与原生工具调用

依据：[ADR-0005](../adr/0005-model-adapter-and-agent-loop.md)（已采纳）§4、§5、§6.6-8、§8.1、§8.4 · 约束：[ADR-0002](../adr/0002-graded-assistant-authorization.md) §3 · 执行：Sonnet 5.5 子代理（leader 派发）· 审查 leader · 阶段：第二阶段

K-2 拆为两段**串行**执行，避免两个执行者同时改网关与助手：

| 段 | 分支 | 范围 |
|---|---|---|
| **K-2a 核心** | `task/k-2a-provider-streaming` | 见下 |
| K-2b 外围 | `task/k-2b-probe-stream-ui`（K-2a 合入后派发） | 测试连接（§4.5，`capability_probe.dart` 与对话框、“采用”）、兼容模式 `ProtocolStreamView`（§5.3）、`assistant_page.dart` 流式渲染、常见模型能力预设表、迁移后的一次性提示界面 |

## K-2a 交付

按 ADR-0005 §8.1，**不含** K-2b 的部分：

1. `services/models/model_provider.dart`：`ModelCapabilities`、`ModelProvider`、`ModelRequest`、sealed `ModelEvent`（§4.1）。
2. `services/models/openai_compat_provider.dart`：SSE 解析、`arguments` 跨块拼接、`[DONE]`、`usage` 末块、旧式 `function_call`、工具名编码（把 `llm_selection_eval.dart` 的编码 / 解析迁到共用位置，评测器改用它，评测结果与现有测试不变）。
3. `model_gateway.dart`：抽出唯一出口 `OutboundChannel`（§4.4）；新增流式入口（连接 15 s、空闲 60 s、单请求绝对上限 min(剩余活动预算, 5 min)）；`chat` / `request` / `embed` 签名与行为不变（`model_gateway_test.dart:97` 断言 `stream:false`）。
4. 出站账本：§5.2、§5.4 的新列（如 `bytes_received`、`first_byte_ms`、`request_digest`）与 `finish` 参数，经 `workspace_repository.dart` 新迁移；不改 CHECK 约束；“记不进账就不发送”在流式下保持。
5. `ModelProfile` 可选 `capabilities`；`toJson` 写出完整 `capabilities`；代码构造默认兼容、非流式；`platform_shell_personal.dart:148` 的表单显式 `streaming: true, source: preset`（只改构造参数，不做新界面）。
6. 存量 profile 一次性设置迁移（`app/bootstrap.dart`，只限 `purpose = chat`，`modelProfilesSchema = 2`，幂等，不放在 `ProfileRepository.all()`）；提示界面留给 K-2b，K-2a 只写一个“待提示”标记。
7. `assistant/model_request_gate.dart`：`AlwaysConfirmGate`。
8. `personal_agent.dart`：按任务冻结的 `capabilities` 选路径——兼容非流式走原 `gateway.chat`；兼容流式走新流式入口，`Done` 后严格解析与纠正路径不变；原生模式走 `ModelProvider`，消息类型扩展 `tool_calls` / `tool_call_id`，工具提议仍经 `ToolRegistry.prepare` 与确认，协议违规整条丢弃只追加固定纠正（§6.2 S3）；端点拒绝 `tools` 或 `stream: true` 时固定原因失败（`stream_rejected` 等），**不**隐式回退。
9. 压缩接缝（§6.6-8 中属于 K-2 的部分）：`contextTokens` / `maxOutputTokens` 字段、token 估算器（ASCII `bytes ÷ 4`，非 ASCII 每字符 1 token，有实报以实报为准）、请求视图接缝。**不实现**压缩本身（K-3）。

## 约束

- §8.4 列出的现有测试**一律不改**；确需改动先停下回报理由。
- 不做：预算循环、并行执行、批量确认卡、事件表、授权、压缩器、K-2b 的界面。
- 不放宽 ADR-0002 §3；密钥只经现有凭据存储，不打印；错误文本经脱敏（P0-S1、P0-S2 的函数）。
- 不访问真实模型；所有测试用回环假端点。

## 测试（K-2a 部分，取自 §8.1）

`openai_compat_provider_test`（SSE 分片、跨块 `arguments`、`[DONE]`、`usage` 末块、旧式 `function_call`、未知函数名、`length` 截断、DSML 当文本）；流式账本（先入账、`begin` 失败不发送、断流 `failed` + `bytes_received`、取消 `cancelled`、空闲超时与绝对上限 `timeout`、`first_byte_ms`）；原生模式端到端（假端点：工具提议仍需 `prepare` 与确认；拒绝 `tools` 固定失败且不改发 JSON 协议）；兼容流式（`Done` 后严格解析与纠正不变；`stream: true` 被拒固定失败）；脱敏（SSE 错误事件与断流不泄露密钥）；能力冻结与默认兼容；存量迁移（写入键、只限 chat、幂等、`all()` 无副作用、用户关闭后重启不被改回、`toJson` 完整、代码构造仍走 `gateway.chat`）；账本迁移；`request_digest` 兼容模式逐字节不变；token 估算器（中文、混合、实报优先）。

## K-2b 交付（K-3b 合入后派发，2026-10-07）

前置：K-2a、K-3、K-3b 已合入（助手核心已拆为 `agent_*.dart`）。

1. **测试连接**（ADR-0005 §4.5）：`services/models/capability_probe.dart`（固定探测载荷常量与摘要，不含用户数据；P1 必做：虚拟工具 `probe_echo` 永不注册永不执行、`stream: true`、用量；P2 可选：JSON 模式、并行调用）；每次探测经 `ModelRequestGate` 与唯一出口入账（`caller = capability_probe`），确认卡文案含“将向该端点发送凭据与固定探测内容”；结果只写 `detectedCapabilities`（含按预设表回填的 `contextTokens` / `maxOutputTokens`），用户点“采用”后才写入 `capabilities`；判定分支：是 / 否 / 未确认 / 未能判定。
2. **常见模型能力预设表**：`services/models/model_presets.dart`（模型 id 前缀 → `contextTokens`、`maxOutputTokens`、是否原生工具 / 流式；只作建议值，经用户采用）。
3. **模型 profile 页**（`screens/platform_shell_personal.dart`）：测试连接对话框与“采用”；按 profile 关闭流式的开关；迁移后的一次性提示（读取 K-2a 写的 `modelProfilesMigrationNotice`，显示一次后清除）。
4. **流式草稿与兼容模式显示**（§5.3）：助手核心向界面暴露只读的草稿流（仅内存，不入载荷、不入会话；任务事件只记长度与摘要，Q4）；兼容模式 `ProtocolStreamView`：`type` 未知时只显示进度，确认为回答后只显示反转义的 `answer` 文本，工具调用只显示“正在准备调用工具”，非 `{` 开头只显示进度；`Done` 后严格解析与纠正路径不变，解析失败的草稿丢弃并提示（不引用模型原文）；原生模式显示文本增量。`screens/assistant_page.dart` 渲染草稿。

**约束**：ADR-0005 §8.4 守护测试与 `north_star_chain.dart` 不改；不改载荷键、摘要、预览字节；探测与草稿不得绕过闸门与账本；不放宽 ADR-0002 §3。

**测试**：探测（固定载荷常量与摘要、不含用户数据、经账本与闸门、虚拟工具永不执行、各判定分支、结果不自动生效、采用后才写入）；预设回填进检测结果；迁移提示只出现一次；关闭流式后重启不被改回；`ProtocolStreamView`（增量只含 `answer` 文本，从不出现协议 JSON / `toolId` / DSML；`type` 在后的缓冲；非 `{` 开头只显示进度；草稿不入载荷）；widget 测试覆盖测试连接对话框与草稿渲染。

**验证**：`flutter analyze` 无问题；新测试与宿主全量通过；E-1 夹具通过；变异至少覆盖“探测结果自动生效”“草稿泄露协议 JSON”“草稿写入载荷”。
