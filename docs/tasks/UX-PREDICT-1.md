## 已确认行为与设计建议

输入区展示可点击的预测胶囊，帮助用户准备下一句。**点击只把建议填进输入框，不自动发消息、不提交业务、不执行工具、不创建确认卡。** 用户仍主动发送。普通问答和范围内只读回答不新增业务确认；首次/未授权远程模型端点与外发仍依既有gate取得必要确认，不允许为满足“零确认”绕权限。后续用户主动请求的写入/外传依 [ADR-0002](../adr/0002-graded-assistant-authorization.md)及现有gate处理，不因采用建议获得授权。

首版设计建议：最多3个短句候选，复用现有Choice/按钮与视觉token，文案称“建议”；建议出现/隐藏不移动输入焦点、不覆盖正在输入的文字。已有非空输入点击候选时，按明确选择的“替换草稿”语义填入并提供本地撤销；这是输入操作，不弹业务确认。若不采用替换语义，评审须明确插入点/选择区规则后再实现，不能两种行为混用。不承诺预测准确率或持续联网。

建议来源分两级：首版可用宿主已登记目的与本地模板；模型预测是后续适配选项，不能把每次按键送到模型。用户选择的模型/端点、上下文最小化、敏感信息遮盖、预算/触发节流和关闭开关须在接入前审定。采用胶囊不授予外传权限；远端预测的请求仍走现有model_request_gate/出站账本，未获准时提供本地候选或不显示，不自动换端点。原始本地路径、凭据和完整业务附件不能作为预测提示自由外发。

## 交付与边界

1. 短流程稿：空输入→有候选→点击填入→人工编辑/撤销→主动发送；同时呈现加载、空、错误、离线、关闭态，失败不得阻断普通输入。
2. 事件/状态矩阵：候选绑定conversationId、requestId、inputRevision；取消/切会话/停止/销毁/输入变更后旧结果不得发布。输入建议请求可取消；不能把停止建议说成取消已经开始的业务IO。重复点击同候选只填入一次相同草稿，不触发发送。请求在途同版本去重，重试产生新requestId。
3. 输入法合成期间不提交或改写预编辑文本，暂停替换/候选快捷键；合成结束后重新检查输入版本。键盘↑↓/Tab移动候选焦点、Enter仅在候选明确聚焦时填入，发送快捷键沿原输入约定；Escape收起，保留草稿。
4. 数据契约只传受限的展示文本与宿主身份，候选不携tool payload、路由、grant、operation或自动发送flag；拒绝超长、未知结构和陈旧revision。将文案中的URL/命令视作文本，不执行、不导航、不预取。
5. 手机避让键盘/安全区，候选可横滚或换行；桌面短窗口不挤掉输入和停止按钮。48触控区、200%文字缩放、读屏“填入输入”、主题/减少动效/只用文字设置。无需触屏或精确鼠标悬停才能访问。

共享文件：assistant输入owner持有 `apps/muyon/lib/screens/assistant_page.dart` 及新独立输入组件/测试；planning/core、catalog/surface由F5b保持，若需公共接口由owner接补丁。生产接入排在输入owner交接窗口；不重写单runtime、两模式planning、stream parser/validator/renderer。现有Intelligent UI组件范围沿 [AI原生方案 §5.2](../design/ai-native-ui-redesign-2026-10-09.md)与F5b的33组件核验，不为胶囊另造语言或任意Widget执行入口。

## 评审与实现验收

| 场景 | 必须实际断言 |
|---|---|
| 点击建议，含URL/命令/业务写入字样 | 输入内容更新；send、tool handler、授权/确认、导航、网络预取计数均0 |
| 非空草稿/IME合成/重复点击 | 明确替换/撤销政策；合成文本不损坏；未发送，草稿revision一致 |
| 晚返回/连续修改/切会话/销毁/取消 | 旧候选不覆盖新输入，取消后不setState；同版本请求去重 |
| 普通问答主动发送 | 使用正常问答路径，无新增业务确认；首次/未授权远程模型端点仍确认，受保护写入/外传仍需原有授权，不以零确认绕gate |
| 离线/模型不支持/无授权/错误/限额 | 输入和主动发送可用，本地退路或不显示；无隐式远端fallback |
| 手机/桌面/键盘/读屏/200%字号 | 候选可达，输入焦点/滚动不丢，发送和停止不遮挡 |

设计阶段验收：上述流程、来源与矩阵获父任务review；若模型适配涉及新公共API/外发政策，提交独立决策记录或ADR提案，未决定时仅交本地模板路线。获派实现后先行为RED再GREEN，定向widget/并发拒绝与包analyze、固定源/组合CI；设备和模型质量另记，模拟预测不能写真实模型通过。最终回报按 [REVIEW](REVIEW.md)，原始日志不入库，摘要写提交。本文不是这些运行验收已通过的证据。
