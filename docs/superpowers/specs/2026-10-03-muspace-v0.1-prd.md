# MuSpace V0.1 一页 PRD

2026-10-03 · 待用户审阅 · 与[主规格](2026-10-03-muspace-v0.1-design.md)配套。

**用户与价值。** 单用户研究者在本人 Mac 与 Android 手机间阅读、整理并显式交换资料；既有 research-skill 用户保留原记录、关系与研究任务。助手针对已选论文给出处明确的建议，原始资料与人工判断始终可独立使用。

**发布建议。** macOS arm64＋Android 实机 release；Windows 只构建兼容级，CI资源另经授权，不作实机支持声明。保留独立 workbench 和询价应用入口。完整询价/原型接入、PaddleOCR、完整1对1 IM、Dream/Laya、向量引擎和应用级加密分后续独立规格；路线未取消，此分期需用户确认。

**规模假设与性能目标（待实测，非保证）。** 单人工作区建议基准为200份文字 PDF、每份≤100页、每份≤30MiB、总原文≤2GiB；现有包兼容仍保留原包限制，选定150MiB研究包目标需双端确认。在指定 MacBookAir 与 vivo V2324A 上记录版本/语料hash，各重复至少20次冷/热场景：PDF首次可读页p95≤3秒；已索引FTS前20条p95≤500ms；笔记保存反馈p95≤300ms；20页文字PDF解析+索引p95≤30秒。问答不承诺统一时延，展示阶段与可取消，按端点单独报告。未达标须修订预算/范围并审阅，不从旧spike单次计时推断通过。

**格式边界。** 首版保留目录/ZIP、skill JSONL、task/result v1、Markdown报告，新增科研包；BibTeX/RIS/Zotero直接互通后置，需要codec和附件映射的独立规格，不伪称已支持。DOI/Crossref为用户点选的联网补充，不上传PDF。

**证据与决策。** 验收记应用commit/build、语料许可/hash、设备OS、parser/profile、步骤实际结果、截图或结构化输出、冷热p50/p95/RSS；历史测试与当前release分开。当前无本版产品验收声明。待确认：推荐A及macOS/Android首发、完整IM/OCR等分期、明文个人单用户资料边界与规模性能目标。确认后才写实施计划。
