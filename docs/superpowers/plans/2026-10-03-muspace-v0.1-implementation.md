# MuSpace V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 复用现有科研模块，交付 Mac 与 Android 的离线论文阅读整理、限定问答和显式研究包接续闭环。

**Architecture:** Flutter 外壳通过类型化适配器接入科研模块；领域 SQLite/文件仓和独立应用入口保留，外壳只拥有工作区目录、授权和模型调用记录。阅读/FTS/锚点等沿用领域交付，助手执行固定检索、生成、核验、用户保存流程。系统文件交换先完成接续，TLS 文件传输是条件能力，不以新 IM 为前置。

**Tech Stack:** Flutter/Dart、Riverpod 稳定 API、go_router；外壳 SQLite，科研默认复用 pdfrx 2.6.5/pdfrx_engine 0.6.1 和领域 sqlite3。上述为已核验科研基线，不代替执行时兼容验证；其他依赖版本在任务1/2经实际兼容测试锁定，不在计划中虚构版本。无首版 OCR、向量数据库或 Android 本地 LLM 依赖。

**Spec:** [设计规格修订2](../specs/2026-10-03-muspace-v0.1-design.md)、[PRD R01–R11](../specs/2026-10-03-muspace-v0.1-prd.md)、[复用矩阵](../specs/2026-10-03-muspace-reuse-matrix.md)、[21项处置](../../reviews/2026-10-03-muspace-spec-review.md)，基线提交 `e14e10f`。用户已批准据此进入计划；本计划待审阅并选择执行方式，当前所有步骤均未执行。

## Global Constraints

- 本轮只写计划并本地提交；下面的创建、代码、依赖解析、构建、测试命令均是未来步骤，不在计划写作阶段执行。计划批准不自动授权修改兄弟仓、安装完整Xcode、创建外部CI或推送。
- 采用方案A，不复制兄弟仓lib、不立刻合库、不重写第二套ResearchCase/阅读索引/修订图。第一方静态模块不宣称沙箱隔离。询价完整接入后置，保留其独立入口与领域规则。
- macOS arm64＋Android 实机 release；Windows 只构建兼容级，没有Windows环境/已有授权CI时记录blocked，不据Mac静态检查声称通过。完整Xcode、Mac签名/公证、PDF native库许可分别是发布门槛；本轮不安装。
- 公共引用为 `NamespaceObjectRef={moduleId,storeInstanceId,objectType,objectId,revisionRef?}`；业务事实与修订由领域模块维护，外壳目录不造第二条链。
- 内容锚点为PDF digest＋0起始pageIndex＋exact/prefix/suffix＋可选bbox/position/parser；bbox未旋转左上0..1，保留cropBox/rotation；metadata改字不改变锚点。多候选/无匹配需确认，旧offset不套新parser。
- 新可交换卡/笔记修订为全局UUID revisionId＋parents，本地整数仅展示；旧native revisionRef保真。去重键 `(namespace,objectId,revisionId)` 不含digest，同revision异内容冲突，ancestor快进/divergent保留两head，缺父记录不快进。
- 5个公开科研工具与UI同领域接口；MCP注解不授权。范围授权绑定endpoint identity×论文ID/digest×数据类别×期限，每次调用复查；覆盖/删除/导出/发送单动作另绑inputDigest。
- 固定模型子集 `/v1/chat/completions`、model/messages、非流式文本；不承诺tools/JSONmode/stream/vision/embedding。默认loopback，不启LAN监听；localhost不等实际本机推理，缺模型立即不可用，无静默云回退。
- 本机事务operationId解决本地幂等；unknown只用于不确定外部副作用并先对账。取消不撤回，ACK不等导入或已读；外来指令当资料。文件staging可恢复，删除立即从派生索引/上下文排除。
- FTS中文bigram＋英文数字词、有限OR/BM25和scope，去重查询词建议≤16。质量不达标退关键词页级引用，缺证据不生成有依据回答。
- PRD基准：200份文字PDF，每份≤100页、≤30MiB，总原文≤2GiB；150MiB研究包目标须双端合同确认。12份合法PDF/20锚点、40检索问题Recall@5建议≥0.85、20问答场景；每性能场景冷/热至少20次，p95首可读页≤3秒、FTS前20条≤500ms、保存反馈≤300ms、20页解析索引≤30秒。均为待测目标，不保证已达标。
- OS私有存储、按需系统文件权限、安全secretstore必需。明文单用户有权存储资料边界与应用级加密后置沿用批准规格，不承诺抵抗同用户进程或擦除对端/备份。
- 320/390/430 logical px、200%字号、键盘/语义标签/减少动效；手机未选论文提示选择，不擅用全库或联网。
- 未来每次提交核对 `git -C <muspace工作树> rev-parse --show-toplevel`，仅add任务Files列出的实际变化；不用主目录git add -A、不提交.DS_Store、不推送。隔离工作树在用户选定执行方式后按using-git-worktrees流程创建，本轮不创建。

## Review Focus

1. **同标题不同PDF、同PDF改作者、重复引句与parser变化**：内容身份与metadata分离，歧义不误绑。任务5测试 `metadataEditDoesNotMoveAnchor`、`duplicateQuoteNeedsConfirmation`、`foreignParserFallsBackToPage`。
2. **端点或论文内容在点击授权后变化，以及未选论文/含恶意指令材料**：调用前复查，不扩scope，不因模型提议执行其他工具。任务7–9测试 `changedPayloadRejectsAction`、`changedDigestBlocksOutbound`、`sourceInstructionNeverDispatchesTool`。
3. **同revision异digest、并发两head、缺父记录、旧v1/skill陌生扩展字段**：冲突可见而不覆盖，旧来源保真。任务3/10测试 `legacyUnknownFieldsSurvive`、`revisionCollisionIsRejected`、`divergentHeadsAreRetained`、`missingParentsDoNotFastForward`。
4. **进程终止于文件落盘和数据库提交之间、同operationId回调重入、删除后模型响应晚到**：staging对账、本地回执复用、晚到结果不能复活。任务9/11测试 `sameOperationDoesNotDuplicateCard`、`restartReconcilesStaging`、`lateAnswerCannotRestoreDeletedSource`。
5. **取消系统文件选择/分享或收到ACK但尚未导入，模型超时有外部计费不确定性**：保留已完成数据，结果状态分开，不换ID盲重发。任务8/10/12测试 `pickerCancelLeavesStoreUnchanged`、`receivedIsNotImported`、`modelTimeoutDoesNotCommitCard`。
