# Miyono / MuSpace：基础平台优先执行清单

授权依据：用户 2026-10-04 提供完整初始需求，明确先完成个人 AI 助手、统一基础平台与公共能力平台。此前科研优先的 V0.1 和 Folio 优先迁入作为已有工作保留，本次调整后续施工顺序，不回写旧共识授权。

## 实现原则与边界

1. 一个 Flutter 宿主、一个业务规则源、一个公共能力实现；完整业务页仍可独立打开。
2. 所有核心查看、编辑、查询与管理在模型离线时可用。模型目的地、使用的上下文与外传内容由宿主展示并逐次确认；不自动切换模型。
3. 工具元数据、参数校验、范围校验、任务和结果引用走统一通路。模型只能建议调用，不能制造操作授权。
4. 复用现有 workspace/settings/execution_records 权威数据，不另建竞争权威。文件、原文引用、权限和传输摘要保留。
5. 本次通用平台不以挂载科研/Folio 页面冒充公共能力已接入；也不以 unavailable/空 adapter 冒充 OCR、向量或通信已实现。

## 方案取舍

- 采用原生 Flutter 宿主服务+静态模块：可离线复用现有规则，改动可审查；代价是需明确跨模块上下文与注册接口。
- 不采用“再建一套插件内 AI 服务”：虽然单模块短期快，但违反公共能力只建设一套，产生重复凭据/权限/任务权威。
- 不采用“先建公网与全量自动同步”：近期目标可由包交换和在线本人设备通信满足，新增服务器会扩大依赖与冲突处理范围。

## 验证与停止条件

- 真实业务规则：平台与 Agent 工具对同一输入得到与原 Folio/科研 API 一致结果，结果可跳回对象；坏参数、错范围、陈旧授权拒绝。
- 权限：伪造模型消息/工具参数不能确认写入或外传；授权绑定工具/上下文/参数/endpoint/过期时间，逐次消费。
- 持久性：进程重开恢复会话与任务记录，正在运行变中断；关闭会话不抹掉任务；取消后无迟到写入。
- 知识：文本 PDF 与本地文件共享索引、来源摘要/页码可核对；向量模型/维度/资料版本不匹配拒绝；无模型仍可关键词查找。
- OCR：真实图片输出文本、坐标和置信度；模型/平台不可用明确诊断，不能以 mock 结果验收真实能力。
- 通信：包篡改/路径穿越/重复接收/取消测试及真实双设备待验证；不把本地 loopback 算设备验收。
- 平台：320/390/430/1280 宽度、放大文字、浅深主题、离线/空/错误状态；静态分析、相关回归、Android 构建。macOS/Windows 缺工具链时明确未验收。
- 首先完成可复核代码与自动验证；缺模型/实机/平台工具链属于外部验收缺口，不隐去需求、不伪造通过。
