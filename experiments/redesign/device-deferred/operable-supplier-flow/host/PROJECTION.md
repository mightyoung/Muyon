# RD-P08 host projection v1

This is a private synthetic lab. M03 is blocked_contract. P07 remains the only normalization, CAS, idempotency and receipt-verification implementation.

Start: `node host/server.mjs --data /tmp/PRIVATE_NEW_DIRECTORY --port 8787` from this experiment directory. The host binds only 127.0.0.1. Data directory must be private (0700); it holds P07 SQLite and host journal. Existing directory is accepted only with a complete valid journal/DB pair. Binary is fixed `/tmp/rd-p07-independent-target/debug/rd-p07-atomic`, SHA256 `62232d1bdec9f923058dd9446b644781737caef9e111dc4dbb5658afe54c674c`.

## Browser interface

GET `/api/state`, POST `/api/action`. Responses contain `suppliers`, `selected`, `editor`, `capability` exactly as parent CONTRACT, plus `session`, `csrf`, `list_status`, `recoverable_sessions`. `recoverable_sessions` is `[{session,supplier,status}]` with nullable supplier/status for empty editors; explicit restore selects that existing session header and GETs state, never creates an intent. `capability` is a string. `list_status` is `available`, `partial`, or `unavailable`; the list consists of separate current reads, never an atomic snapshot. `selected` and `editor.current` are `{supplier,name,revision}` or null. `editor.preview` is `{normalized_name,candidate_revision}` or null. `editor.receipt` is verbatim P07 receipt or null. `reason` is null or a safe fixed protocol/display reason.

First GET without `X-RD-P08-Session` creates a durable session and returns its opaque UUID. Store it in `sessionStorage` (per tab) and send it in `X-RD-P08-Session` on all later GET/POST requests, including after reload or host restart. Unknown supplied session returns 409; never silently replace it. New tabs without an existing session create independent editors over the same SQLite fixture. Session limit is 32. POST requires `Origin` equal to the exact `http://127.0.0.1:PORT`, `Content-Type: application/json`, and `X-RD-P08-CSRF` matching the per-start nonce from GET. Refresh GET after restart to obtain the new nonce. Nonce is local CSRF defense, not a business credential or permission grant.

Actions have exact fields: `{action:'select',supplier:'S1'|'S2'}`, `{action:'edit'}`, `{action:'draft',raw:STRING}`, `{action:'preview'}`, `{action:'save'}`, `{action:'cancel'}`, `{action:'lookup'}`. GET refreshes current rows. Successful actions return the full projection. Invalid action/state returns non-2xx JSON `{error:SAFE_CODE}`; preserve existing UI state and refresh. No write retries. JSON duplicate keys, extra fields, malformed bodies, bodies above 32768 bytes, foreign Host/Origin, unknown routes are rejected. Raw accepts up to 8192 UTF16 units as transport bound; P07 validates its own 2000-unit business limit.

Select preserves the existing editor even if another supplier is selected. Edit is permitted only when editor is null; explicitly cancel a resolved/pre-dispatch editor first. Cancel/draft cannot replace a possibly dispatched unresolved operation. Editing a draft retains its intent, clears preview and provisional binding; preview allocates host correlation references, never Rust-issued authority. Save requires prepared state, durably stores complete binding and dispatched marker, then calls commit once. Repeated save on any already-dispatched editor returns its existing state without committing again. Unknown exposes lookup only; cancel/edit/draft cannot hide it. Revision rejection projects conflict with original raw/expected_revision and separately read current row. Confirmed conflict/rejection/saved may be explicitly cancelled before a new edit.

## Persistence and trust boundary

One host owns all sessions and serializes operations globally. An OS flock is held for its lifetime; a second cooperating host on the same directory fails closed. Journal writes use private temporary file, file fsync, rename, directory fsync; dispatch cannot start before durable marker. Journal failure poisons the live host against later writes. Startup refuses corrupt/oversized journal, missing DB or missing journal, invalid sessions/bindings or unsafe directory permissions; never reseeds partial state. Saved projections after restart are obtained again from P07 lookup, not trusted from cached receipt text. Restart restores original dispatched binding and issues only lookup; absent/unavailable/malformed result remains unknown. The host never retries commit to recover.

P07 requests have flat exact `op,domain,scope,supplier` for read/init; binding calls add `intent,operation,raw_utf16,expected_revision,plan,candidate`. Read reply includes `status:'read'` and `supplier:{id,name,revision}`. Preview reply is `status:'preview',normalized_name,candidate_revision` or rejection. Lookup/commit return verified committed receipt, rejected reason, conflict, or unknown (lookup may add `receipt_found:false`). Raw conversion uses JS UTF16 code units unchanged.

Assumptions: trusted local owner and unchanged pinned binary; private synthetic storage; Linux advisory flock and local filesystem semantics. Malicious local file mutation, cross-host access bypassing flock, power-loss guarantees, production retention/authentication, formal grants, real suppliers and platform acceptance are excluded. The host does not expose fault injection. Tests own process-kill barriers and inspect physical SQLite separately. No sessions are automatically evicted; preserve directory and journal for evidence.
