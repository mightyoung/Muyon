# RD-P08 experimental operable flow boundary

Private synthetic Linux laboratory only; v1.3.2 D01.1 page intent applies. M03 remains blocked_contract. This is not production authority, schema, platform or migration acceptance. P07 source remains unchanged and sole business implementation. UI only requests trusted host actions and renders host projection.

## Shared experimental projection and HTTP actions

`GET /api/state` returns `{suppliers, selected, editor, capability}`. suppliers are fixed synthetic S1/S2 records `{supplier,name,revision}` (revision canonical decimal text); list composed via separate P07 reads and identified as non-atomic. selected is record or null. editor is null or `{intent,supplier,raw,status,expected_revision,preview,current,receipt,reason}`. raw is original JS string; status is one of `editing,prepared,saving,saved,conflict,unknown,rejected,unavailable` for display only, not new business state enum. preview is null or actual `{normalized_name,candidate_revision}`; current is actual current row projection; receipt is null or verbatim P07 original receipt. capability is honest fixed experiment/M03 blocked text. Host response can include a same-origin nonce for POST protection; it confers no production authority.

`POST /api/action` accepts exact `{action,...allowedFields}` for select(supplier), edit(), draft(raw), preview(), save(), cancel(), lookup(). Each request includes server-provided CSRF nonce as `X-RD-P08-CSRF`; Origin and Host must exactly match trusted loopback URL. Host validates strict envelope/field types/body limits and never accepts renderer DB paths/domain/binding/fault/process args. No CORS. Server serves only owned desktop assets, no arbitrary paths. API failures surface unavailable/rejected, never saved.

select changes selection without creating an intent; explicit edit creates a durable host-owned stable intent. Changing selection must preserve any unresolved original editor/binding, never replace it implicitly. Input changes affect local durable draft and invalidate a prepared binding; never silently rewrite dispatched/unknown original binding. Host allocates plan/candidate as experiment references bound to full raw UTF16/domain/scope/supplier/revision, explicitly not Rust-issued authorization. Preview calls actual Rust validation. Before commit, full original binding and dispatch state persist; process/reply loss or uncertain state restores same binding and uses lookup only. P07 Revision rejection is UI conflict with actual current record and original draft; user may cancel/start fresh edit explicitly, never auto overwrite revision. Same-intent replay returns original receipt without second effect; UI saved requires actual committed receipt, not click acknowledgement. If current row changes again, original receipt remains historical and current row renders separately.

Host journal lifetime/path/concurrency implementation must be documented in host/PROJECTION.md and independently verified before combination; corrupt/missing original binding cannot be replaced by new intent automatically. Trusted synthetic setup may provision S2 with fixed parameter-bound insert in private fixture DB; no SQL or seed endpoint exposed to browser. No real suppliers or private data. Fault injection is test-owned only, not runtime renderer controls. Cross-process session/DB and disk-power-loss/product security claims are excluded unless actually proven.
